# テキスト（Markdown・テキスト・CSV）

メモや表のデータを、画像・ファイルと同じ場所にしまって探せるようにする。
4 つ目の種類「テキスト」（`items.kind = 'text'`）として、取り込み・新規作成・見る・書き換える・中身で探すまでを扱う。

## 決定（2026-10-16）

| 論点 | 決定 |
|---|---|
| 対象 | `.md` / `.markdown` / `.txt` / `.csv` / `.tsv` |
| 種類 | 新しい種類「テキスト」。画像・ファイルと同じフォルダ・タグ |
| 見る | Markdown は整形して表示（見出し・表・リスト・コード）、CSV / TSV は表、テキストはそのまま |
| 書き換える | **アプリ内で編集できる**。作ったものも取り込んだものも。「取り込んだ元ファイルは書き換えない」（ROADMAP）の、テキストだけの例外 |
| 新しく作る | 「新規テキスト」（⌘N）。開いているフォルダに `.md` で作り、すぐ編集を始める。文字だけを一覧に貼り付けても、その文字のテキスト（`.txt`）ができる |
| 中身で探す | 検索欄で、名前・メモ・タグと同じように本文も探す |

## 文字コード

社内の CSV は Shift_JIS が多いので、読むときに判定し、書くときは元の文字コードで書く。

- 読む：BOM（UTF-8 / UTF-16）→ UTF-8 として正しい → Shift_JIS として正しい、の順に判定する。どれでもなければ、
  壊れた文字を置き換えて表示だけする（**編集はできない**。保存すると元のバイト列が失われるため）
- 書く：元の文字コードと改行（CRLF / LF）のまま。Shift_JIS で表せない文字（絵文字など）を入れたときは、
  BOM 付き UTF-8 で保存し、そのことを表示する（Excel でも文字化けしない）
- NUL を含むもの（バイナリ）は、拡張子がテキストでも取り込まない

## 保存

- 編集は自動で保存する（入力が止まって少ししたら。⌘S ですぐ保存）。閉じる・前後へ移るときも、保存していない分を保存する
- 保存すると、ファイル・大きさ・ハッシュ（重複の判定用）・サムネイル・検索用の本文を作り直す。
  サムネイルは新しい名前で書く（一覧が古い画像をキャッシュから出さないように）
- 書き込みは同じフォルダの一時ファイルに書いてから置き換える（途中で落ちても元のファイルが壊れない）
- 編集の取り消しは、編集欄の中の取り消し（⌘Z）だけ。保存した版の履歴は持たない
- 10 MB を超えるテキストは、先頭だけを表示し、編集はできない

## 表示

- ビューアの上に［プレビュー｜編集］を置く。テキスト（`.txt`）のプレビューは等幅でそのまま
- Markdown は `marked` で HTML にし、許可したタグと属性だけを残してから画面に入れる（取り込むファイルは信用しない、
  ARCHITECTURE.md「外から来るファイル」）。スクリプト・iframe・フォームは捨てる。リンクは既定のブラウザで開き、
  画像は外のものを読み込まない（CSP。代替テキストだけを出す）
- CSV / TSV は引用符・改行を含むセルも読む。先頭の行を見出しにする。多いときは先頭の 2,000 行まで
- 色：プレビューの「紙」（テキスト・Markdown・CSV）はテーマに従う。ライトは白地の GitHub 風、ダークはエディタ風の青みがかった灰
  （地 `#292d32`、文字は生成り、見出し青、リンク・コードは緑）。色は `features/texts/text.css` の `--tx-*` に集め、
  ライトとダークで値だけ替える。PDF・Office のプレビューは中身が自前の描画なので白のまま
- サムネイル：本文の先頭を紙のように描く（Markdown の見出しは太字、CSV は表）。右下に形式（MD / TXT / CSV）

## データ

- `items.body`（step 22）：検索用の本文。先頭の 1 MB まで。テキスト以外は NULL
- 幅・高さは 0（ファイルと同じ）。重複の候補・回転は対象外
- ライブラリ間のコピーは本文も一緒に移る（`items` の列をそのまま写すため）

## 使う種類

使う種類（docs/SETTINGS.md）を設定で選んだことのあるライブラリでは、テキストは使わない種類のまま。
テキストを取り込む・作ると、いつものトーストで知らせ、使う種類に足せる。選んだことのないライブラリは、はじめからすべての種類を使う。

## キー

⌘⌫ / Ctrl+Backspace（ゴミ箱へ移動）はメニューのショートカットなので、文字の入力中にも届く。
入力欄（テキストの編集欄・検索欄など）にフォーカスがあるときは、ゴミ箱へ移さない（`commands.ts` の `item.trash`）。

## 古い版で開いたとき

古い版は `kind = 'text'` を知らないので、画像として扱う（一覧のサムネイルは出るが、ビューアでは開けない）。
壊れはしない。
