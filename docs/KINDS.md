# 種類で絞る：サイドバーの範囲

**決定・未実装**。モック（3 案）を比べて、C（サイドバー上部の 1 行のメニュー）にした。

使っていて困っていること：

- 最初は画像・動画を管理するアプリとして作り、あとからファイル・テキスト・ブックマークを足した。そのため、今はいろいろな種類が 1 つの一覧に混ざっている
- 種類を選べるのは絞り込みの行の「種類」のチップだけ。評価やタグのような使い捨ての条件と同じ並びにあるので、「ファイルだけを見たい」ときに探しにくい
- 「種類」は場所（フォルダ・タグ）を移っても残る（[NAVIGATION.md](NAVIGATION.md)）。ほかの条件と動きが違うのに、見た目は同じチップ
- サイドバーの件数は種類に関係なく全部を数えるので、「このフォルダに画像がいくつあるか」が分からない

## 決定

種類は「その中をどう絞るか」（絞り込み）ではなく **「何を見ているか」の範囲** として扱い、サイドバーに置く。

| 論点 | 決定 |
|---|---|
| 置き場所 | サイドバー上部、［ストック｜フォント］のセグメントのすぐ下に **1 行のメニューボタン** を置く。絞り込みの行の「種類」のチップは無くす |
| フォルダと同じ「場所」にしない理由 | 場所は 1 つだけ選ぶもの（[NAVIGATION.md](NAVIGATION.md)）。種類を場所と同じ並びにすると、押した時点でフォルダから抜けてしまい、「このフォルダの画像だけ」が見られなくなる。範囲は場所と別の段に置き、組み合わせて使う |
| 「すべて」の扱い | 種類の側には **「すべて」を置かない**。何も選んでいなければすべての種類を出す。「すべて」という言葉は、サイドバーの場所の「すべて」だけに残す（2 つあると意味が伝わりにくい） |
| ボタンの表示 | 何も選んでいないときは「種類で絞る」（絞り込みのアイコン、面は控えめ）。選ぶと種類の名前（「画像」「画像・動画」）に変わり、`tonal` の塗りになる。1 種類だけならその種類のアイコンを出す |
| メニュー | 先頭は「種類で絞らない」。その下に使っている種類を並べ、チェックと件数を出す。件数は **今開いている場所の中で** 数える |
| 選び方 | クリックで 1 つ選び、メニューを閉じる。選んでいる種類をもう一度選ぶと解除する。⌘クリック（Windows は Ctrl）で重ねて選び、メニューは開いたまま。全部の種類を選んだら「絞らない」と同じに戻す |
| サイドバーの件数 | **範囲に合わせて数える**。画像に絞れば、フォルダ・タグ・スマートフォルダ・未分類などの件数がそれぞれの画像の数になる。0 件になった行も消さず、件数を薄くするだけ（行の位置を変えない。[UI.md](UI.md)） |
| 場所を移ったとき | 範囲は **残す**（今の「種類」と同じ）。ライブラリごとに覚える（今の `lastKinds`） |
| 「すべて解除」 | 範囲は **外さない**（今は種類も外している）。絞り込みの行にもう無いので、そこの「すべて解除」の対象にしない |
| 「条件を保存」 | 範囲も条件に入れて保存する（今どおり。「画像だけ」「PDF だけ」のスマートフォルダが作れる） |
| スマートフォルダの条件に種類があるとき | 範囲と条件の両方に合うものを出す（今の `listKinds` と同じ）。合うものが無ければ、一覧に「条件に合うものはありません」を出す |
| 重複の候補 | 画像だけが対象なので、ボタンを **無効表示** にして「画像だけ」と出す。ツールチップに「重複の候補は画像だけが対象です」と書く。範囲の値そのものは変えない（ほかの場所へ移ると元の範囲に戻る） |
| 出すとき | ストックモードで、使っている種類が 2 つ以上のときだけ（今の「種類」のチップと同じ）。フォントモードでは出さない |
| キー操作 | ⌥1〜⌥5 で種類を 1 つ選び、⌥0 で解除する（案。入力欄にフォーカスがあるときは効かせない）。メニューバーの「表示」にも同じ項目を置く |

### 見た目

```text
┌─────────────────────────┐
│ ［ストック｜フォント］    │
│ [≡ 種類で絞る        ▾]  │  ← 選ぶと [▣ 画像 ▾]（塗り）
│                          │
│  すべて            1,240 │  ← 件数は範囲に合わせる
│  未分類               96 │
│  …                       │
```

メニューを開いたところ：

```text
  種類で絞らない
  ─────────────
✓ 画像         612
  動画          18
  ファイル      40
  テキスト      12
  ブックマーク  88
  ─────────────
  ⌘クリックで重ねて選ぶ
```

### 比べた案

| 案 | 形 | 選ばなかった理由・選んだ理由 |
|---|---|---|
| A リスト | 種類を件数付きで縦に並べる | 場所と重ねて選べることは分かりやすい。そのかわり 5〜6 行ぶんフォルダが下がる |
| B アイコン列 | アイコンを 1 行のセグメントに並べ、下に要約を 1 行 | 高さは小さいが、アイコンだけで種類を見分けられるかに頼る |
| **C メニュー** | 1 行のメニューボタン | **採用**。サイドバーの場所の並びをほぼ押し下げず、今の種類が文字で読める。切り替えは 2 クリックになるが、範囲は頻繁には変えないのでよい |

## 今の実装から変わるところ

| 今 | これから |
|---|---|
| `FilterRow.tsx` の `KindCondition` / `KindMenu`（絞り込みの行の「種類」） | サイドバーの範囲のメニュー（`Sidebar.tsx`、モードのセグメントの下）。絞り込みの行からは外す |
| `get_counts`・フォルダ・タグ・スマートフォルダの件数（`db.rs`）：モードの全種類を数える | 範囲の種類（`filter.kinds`）を受け取って数える。モック（`src/dev/mockBackend.ts`）も同じ PR で直す |
| 「すべて解除」が種類も外す（`store.ts`） | 範囲は外さない |
| 種類の件数は絞り込みの行の `facet_counts` で数える | メニューを開いたときに、今の場所の中で種類ごとに数える（ほかの絞り込みの条件は含めない） |

ショートカット一覧・メニューバー・[FEATURES.md](FEATURES.md)・[ARCHITECTURE.md](ARCHITECTURE.md) の「種類の絞り込み」の説明も、実装と同じ PR で直す。

## 保留

- **画像サイズの絞り込み**：今は一覧が画像だけのときしか使えない。範囲で画像を選べば使いやすくなるが、「先に画像に絞らないと押せない」ことは残る。幅と高さは動画も持つので、「サイズ（px）」として動画にも効かせ、持たないもの（ファイルなど）は自然に外れるようにする案がある。範囲を実装してから決める
- **場所の「すべて」の名前**：種類から「すべて」を外したので、今のところ変えない。それでも紛らわしければ「ライブラリ」などにする
