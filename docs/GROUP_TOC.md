# グループ分けの目次

グループ分け（種類・評価・タグ・フォルダ・年・月など）は区切りが多くなると、いま全体のどこを見ているか、どんな区切りがあるかが分かりにくい。

## 決めたこと

| 論点 | 決定 |
|---|---|
| 置き場所 | 一覧の上端、スクロールしない 1 行（`Grid.tsx` の `SectionBar`）。右端のレールは、情報パネルやシェルフと幅を取り合うので採らなかった |
| 左側 | いま見ている区切りの名前と件数。スクロールに追従する |
| 右側 | 「目次」ボタン。押すと全区切り（色・星・件数つき）のメニューが開き、選ぶとその区切りの先頭へ移る。現在の区切りは強調。外のクリック・Esc で閉じる |
| グループ分け「なし」 | 行は残し、「すべて・N 件」を出して「目次」は無効表示（理由はツールチップ）。切り替えても下の一覧の位置が動かない（[UI.md](UI.md)） |
| 操作 | コマンド `view.toc`（⌘⌥J、表示メニュー）。開閉は保存しない |
| 対象 | 区切りのある一覧すべて（重複の候補の「グループ n」も含む）。空の一覧では出さない |
