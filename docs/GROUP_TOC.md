# グループ分けの見出しと移動

グループ分け（年月・評価・タグ・フォルダ、重複の候補のグループ）は区切りが多くなると、いま全体のどこを見ているか、どんな区切りがあるかが分かりにくい。

## 決めたこと（2026-11-14）

| 論点 | 決定 |
|---|---|
| いま見ている区切り | 一覧の中の区切りの見出し（「2025年4月 28 件」）を、スクロールしても**一覧の上端に貼り付ける**。次の見出しが近づいたら押し出す。半透明の面と影で写真と分ける（`Grid.tsx`、`pinnedTop`） |
| ほかの区切りへ移る | **見出しの名前（▾ 付き）を押す**と区切りの一覧が開き、選ぶとその区切りの先頭へ移る。一覧の見出しは「年月へ移動」のようにグループ分けの名前で書く。貼り付いた見出しでも、一覧の途中の見出しでも同じ。コマンド `view.toc`「ほかのグループへ移動」（⌘⌥J、表示メニュー）でも開く（左上に出る）。外のクリック・Esc で閉じる。開閉は保存しない |
| 見出しの帯のほかの所 | 押すとその区切りをすべて選ぶ（今までどおり） |
| グループ分け「なし」 | **何も出さない**。見出しが無いので貼り付くものも無い |
| 件数 | 区切りの件数の単位はいつも「件」（以前は全部が画像のとき「枚」だった）。紐づけで畳んだ子は数えない |
| 対象 | 区切りのある一覧すべて（重複の候補の「グループ n」も含む。貼り付くのは名前と件数の見出しで、整理のボタンは一覧の中の帯にだけある） |

### 以前の形と、やめた理由

- ~~一覧の上端に、スクロールしない 1 行（`SectionBar`）。左にいま見ている区切りの名前と件数、右に「目次」ボタン。グループ分け「なし」でも行を残し、「すべて・N 件」と無効の「目次」を出す~~
- グループ分けしていないと、「すべて」がツールバーのタイトルと二重に見え、件数も 2 つ（ツールバーは紐づけの子も数え、行は数えない）で数と単位が違って見えた
- 「目次」という言葉では、何の目次で、押すと何が起こるのかが分かりにくかった
- 行を残したのは「グループ分けを切り替えても一覧の位置が動かない」ためだったが、見出しを一覧の中に貼り付ければ、行を使わずに同じことができる（ツールバーとその下の位置は動かず、見出しは一覧の中身として出入りする。[UI.md](UI.md)）
