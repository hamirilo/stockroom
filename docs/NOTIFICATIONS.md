# 知らせ方：その場・HUD・トースト・OS の通知・ダイアログ

困っていたこと：

- トーストの残り時間が、アプリにフォーカスが無いと進まない。Finder からドロップしたあとや、もう 1 枚のディスプレイで見ているときは、見えているのに消えずに残り続ける
- ほとんどの知らせがトーストになっている。コピーしたことも、シェルフに入れたことも、エラーも、同じ右下の枠に出る

## 何を基準にしたか

デスクトップと Web の主なガイドラインで、だいたい一致していること：

| 出どころ | 要点 |
|---|---|
| Apple HIG（Notifications、Alerts） | OS の通知は、アプリを見ていないときに知る価値があることだけ。アプリの中で見えることを通知で重ねない。アラートは判断が要るときだけ |
| Windows（InfoBar、App notifications） | アプリの中の状態は InfoBar（その場に残る帯）。トースト型の通知は OS のもので、アプリの外にいる人へ |
| Material（Snackbar） | 短い、軽い結果の知らせ。同時に 1 つ。操作は 1 つまで。大事なことは入れない |
| Atlassian（Flag）、Carbon（Notification） | 成功・情報は自動で消えてよい。エラー・警告は読まれるまで残す。結果が見える場所にあるならインラインで知らせる |
| WCAG 2.2.1（Timing Adjustable）、4.1.3（Status Messages） | 自動で消えるものは止める・延ばす手段を持たせる（ホバー、フォーカス）。読み上げは `role="status"` / `alert` |
| NN/g（Indicators, Validations, and Notifications） | 変化が起きた場所に出すのが一番伝わる。離れた場所の知らせは見落とされる |

まとめると、**知らせは変化の起きた場所に一番近い形で、見落とすと困る度合いに合わせて強さを選ぶ**。トーストは「その場で見えない結果」のためのもので、何でも入れる箱ではない。

## 使い分け

上から順に検討し、最初に当てはまるものを使う。

| 段 | 使うとき | 例 |
|---|---|---|
| 1. その場 | 操作した場所で結果が見える。部品の表示が変わる、数が増える、光る | コピーボタンが「コピーしました」になる。開いているシェルフへの追加（チップが増え、件数が変わり、光る）。サイドバーでのフォルダの並べ替え（行が光る） |
| 2. HUD | 結果がその場では見えにくい、ごく軽い操作。1.4 秒で消える。操作ボタンは無い | 数字キーの評価、F / P、回転 |
| 3. トースト | 結果がその場に見えない、または戻せる操作。右下、同時に 3 つまで | ゴミ箱へ移動［元に戻す］、取り込み・書き出しの結果、見えていないシェルフへの追加［シェルフを表示］ |
| 4. その場の帯・無効表示 | 続いている状態、前もって分かる「できない」 | 処理中の進捗バー。使えない操作は無効表示＋ツールチップ（docs/UI.md） |
| 5. OS の通知 | 10 秒以上かかった処理が、ウィンドウが前に無いときに終わった | 取り込み・書き出し・ライブラリ間の移動（`lib/osNotify.ts`） |
| 6. ダイアログ | 取り消せない操作の確認、判断が要ること | 完全削除、ペアリングの許可、更新の適用 |

- 「できない」を後から知らせるより、前もって無効表示にする（4）。押せたのにトーストで断るのは最後の手段
- ダイアログの中の操作の結果は、ダイアログの中に出す。後ろのトーストは隠れていたり、ダイアログを閉じるまで目に入らなかったりする
- 結果のトーストをエラーの後に出さない（今までどおり `run`）

## トーストの決まり

| 項目 | 決まり |
|---|---|
| 消えるまで | 文字数に合わせる：2 秒＋1 文字 60 ミリ秒、3〜6 秒（操作ボタン付きは 5〜8 秒）。`toastDuration`（下の「秒数」） |
| エラー | 自動では消さない。× で閉じる（理由を読ませる）。新しいものが来て 3 つを超えたら古いものから消える |
| 止まるとき | ホバー中、中のボタンにフォーカスがあるとき、**ウィンドウが見えないとき**（最小化・隠れている。`visibilitychange`） |
| 止めないとき | ウィンドウが見えていてフォーカスが無いだけのとき。見えているので読める |
| 同時に | 3 つまで。古いものから消える |
| 書き換え | 「確認しています…」のあとの結果は、同じトーストを書き換える（`replace`） |

フォーカスが無いと止める、を止めた理由：ウィンドウの外へ出たのを「見ていない」とみなしていたが、ドロップ元の Finder / エクスプローラが前に残るとき、別のディスプレイで見ているときは見えている。見ていないときに終わった長い処理は OS の通知が受け持つ（5）ので、トーストを止めておく必要は無い。最小化などで本当に見えないときだけ止める。

## 今のトーストの棚卸し

| 種類 | 箇所 | 扱い |
|---|---|---|
| コピーしました | 共有・ブラウザ拡張・Claude 連携のダイアログ | **直した**：ボタンがその場で「コピーしました」になる（`components/Copy.tsx`）。ラベルは同じ幅を取り、隣を押し出さない |
| シェルフに追加しました | `addToTray` | **直した**：シェルフが見えているときは出さない（チップと件数と光り）。詳細パネルが情報のタブ・閉じているときだけ［シェルフを表示］付きで出す |
| インポート中です | `guarded`（取り込みの二重起動） | **直した**：エラー（赤）ではなく情報にした。状態であって失敗ではない |
| ゴミ箱へ・空にする・重複ではない | `lib/actions.ts` | トーストのまま（戻せる操作の［元に戻す］。⌘Z でも戻せる） |
| シェルフから外しました | `removeFromShelf` | **直した**：出さない。シェルフの外からは HUD。戻すのは ⌘Z（下の「取り消し（⌘Z）とトーストの整理」） |
| フォルダへ移動しました | `moveToFolder` | トーストのまま（フォルダの行は光るが、移したものが今の一覧から消えたり、フォルダが画面の外だったりする） |
| 取り込み・書き出し・移動の結果 | `importDone`、`ExportDialog`・`writeLibrary`、`transferTo` | トーストのまま。長くかかってウィンドウが前に無ければ OS の通知も |
| 使っていない種類 | `notifyUnusedKinds` | トーストのまま（行き先のボタン付き） |
| アップデートの確認 | `lib/update.ts` | トーストのまま（設定画面を開いているときは節の中、docs/SETTINGS.md） |
| お気に入り・ピン留めに追加しました | `toggleFavorite`、`togglePinned` | トーストのまま（隠した表示へ行く［開く］が要るときだけ出る） |
| 失敗（`run` の `String(e)`） | 各所 | エラーのトースト。自動で消さなくなった |

### 残り（次に直す候補）

| 箇所 | 今 | 直し方 |
|---|---|---|
| 「いま開いているライブラリです」（`TransferDialog.tsx`） | エラーのトースト | ダイアログの中で、その行を選べないようにする |
| 「このライブラリに〜はありません」（`lib/actions.ts`） | 情報のトースト | 使えないときは操作を無効表示にしてツールチップに書く |
| タグのコピー・貼り付け（`copyTags` / `pasteTags`） | トースト | 貼り付けは HUD と光りで足りる。コピーはクリップボードの中身が見えないのでトーストのまま |
| 見逃したトースト | 消えたら見られない | エラーだけでも、最近の知らせの一覧を置くか検討する。まずはエラーを残すことで様子を見る |

## 取り消し（⌘Z）とトーストの整理（2026-11-13）

困っていたこと：

- シェルフに間違えて入れて外すと、トーストが 2 枚出る（「追加しました」と「外しました［元に戻す］」）。前のものは残ったまま
- 表示が長い。［元に戻す］がトーストのボタンにしか無いので、戻せる操作は必ずトーストになり、ボタン付きは 8 秒から
- 軽い操作（シェルフから外す）も重い操作（ゴミ箱へ移動）も、同じ強さで知らせている

方針：**戻すのは ⌘Z にまかせ、トーストは「その場で見えない結果」と「重い操作」だけにする**。

### ⌘Z（取り消す）

| 項目 | 決定 |
|---|---|
| 入口 | ⌘Z（Windows は Ctrl+Z）。メニューバーの「編集 › 取り消す」も同じ。項目名に何を戻すかを出す（「取り消す：シェルフから外す」） |
| 戻せるもの | 今［元に戻す］を持つ操作すべて（ゴミ箱へ移動・重複の整理・重複ではない・紐づけ・紐づけを外す・シェルフから外す・シェルフを空にする・サイドバーから隠す・動画のサムネイル・Claude の変更）と、シェルフに入れる |
| 何回 | 新しい順に 20 回まで。アプリを閉じる、ライブラリを切り替えると消える（記録はメモリだけ） |
| やり直す（⇧⌘Z） | 今回は作らない |
| 文字の入力中 | 入力欄・テキストの編集中は、今どおりその欄の取り消し |
| 戻したとき | HUD（下の中央、1.4 秒）で「取り消しました：シェルフから外す」。その操作のトーストがまだ出ていれば消す |
| 戻せないとき | 戻すものが無ければ何もしない（Windows のメニューは無効表示。macOS は入力欄の取り消しも同じ項目なので無効にしない）。別のライブラリの変更など戻せないものは、今どおりエラーのトースト |
| トーストの［元に戻す］ | 残す（マウスで戻せる）。⌘Z で戻るのがその操作のとき（いちばん新しいとき）だけ、ボタンに「⌘Z」を添える。どちらで戻しても 1 回だけ |

### 操作ごとの知らせ方

| 操作 | 前 | 決定 |
|---|---|---|
| シェルフに入れる（シェルフが見えている） | 出さない（チップ・件数・光り） | 今のまま |
| シェルフに入れる（見えていない） | トースト［シェルフを表示］ | 今のまま。続けて外したら、このトーストは消す |
| シェルフから外す（シェルフの上で） | トースト［元に戻す］ | **出さない**。チップが消えるのが見える。戻すのは ⌘Z |
| シェルフから外す（B・詳細パネルのボタン。シェルフが見えていない） | トースト［元に戻す］ | **HUD**「シェルフから外しました」 |
| シェルフを空にする | トースト［元に戻す］ | 今のまま（まとめて消えるので、気づいて戻せるように） |
| ゴミ箱へ移動・重複の整理・紐づけ・紐づけを外す・重複ではない | トースト［元に戻す］ | 今のまま（重い・結果が一覧から消える） |
| お気に入り・ピン留め・評価・回転 | HUD（隠した表示へ行くときだけトースト） | 今のまま |

同じものを入れてすぐ外したときのように、**打ち消し合う操作が続いたら、前の操作のトーストも消す**（何も起きなかったのと同じなので、何も残さない）。

### 秒数

| | 前 | 決定 |
|---|---|---|
| ボタン無し | 4 秒＋1 文字 80 ミリ秒、5〜12 秒 | 2 秒＋1 文字 60 ミリ秒、**3〜6 秒** |
| ボタン付き | 同じ式で 8〜12 秒 | 同じ式で **5〜8 秒** |
| エラー | 閉じるまで | 今のまま |

例：「1 件をシェルフから外しました」（15 文字）は 3 秒、ボタン付きなら 5 秒。ホバー中・ボタンにフォーカスがあるとき・ウィンドウが見えないときに止まるのは今のまま（WCAG 2.2.1）。

### 実装のメモ

- 取り消しの記録：`store.ts` の `undoStack`（`UndoEntry`）。戻せる操作は `lib/actions.ts` の `undoable(名前, 戻す処理, トースト)` で記録し、トーストも同時に出す。
  ［元に戻す］のボタンは `undoable` が付ける（［シェルフを表示］のように別のボタンを渡したときはそちら）。⌘Z は `undoLast`
- 入口：コマンド表 `lib/commands.ts` の `edit.undo`。macOS のメニューバーは OS の「Undo」をやめてこれにした（[MENUS.md](MENUS.md)）。Windows は Ctrl+Z を一覧のキー処理だけで受ける
- 入れてすぐ外す：`addToTray` が直前に入れたものを覚えておき、`removeFromShelf` でそれを全部外したら、入れたときのトーストを閉じる
- HUD：`ActionHud.tsx` の `shelfOff`・`undo`

## 決めたこと

| 論点 | 決定 |
|---|---|
| フォーカスが無いときのトースト | 止めない。ウィンドウが見えないときだけ止める |
| エラーのトースト | 自動で消さない |
| 秒数 | 固定（5 秒・8 秒）をやめ、文字数で決める |
| その場で見える結果 | トーストを出さない（コピー、開いているシェルフへの追加） |
| 共通の決まり | desktop-platform の UI Standard §5「フィードバック」に、使い分けとトーストの決まりとして載せる |
| 元に戻す（2026-11-13） | ⌘Z で直前の操作を戻す（20 回まで、やり直すは無し）。その場で結果が見える軽い操作はトーストを出さない |
| 秒数（2026-11-13） | 短くした：3〜6 秒、ボタン付き 5〜8 秒 |
