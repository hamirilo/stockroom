# 動画

ストックの種類 `video`（`ItemKind` / `db::Kind::Video`）。MP4・M4V・MOV・WebM を取り込み、一覧・ビューアで見る。
編集はしない（ファイルはそのまま保管する）。ロードマップのフェーズ 7 を実装したもの。

## 決めたこと

| 論点 | 決定 |
|---|---|
| モード | ストック（`modeOf`）。画像・ファイルと同じフォルダ・タグに並べる |
| 取り込み | ファイルを丸ごとメモリに読まない。ディスクからハッシュを取り（重複判定）、そのままコピーする（`import.rs` の `process_video`、`library::copy_file`）。数 GB でも落ちない |
| サムネイル | OS の 1 コマ（macOS は Quick Look）。取れなければ種類のカード。**Windows は未対応でカードのまま**（シェルのサムネイル API は今後）。自分で選んだ画像にも変えられる（下の「サムネイルを設定する」） |
| 長さ・縦横 | ファイル自身のヘッダから読む（`videos/mod.rs` の `probe`：MP4/MOV は `mvhd`・`tkhd`、WebM は EBML）。ffmpeg は同梱しない。長さは `items.duration_ms`（step 24）、縦横は `width` / `height` |
| コーデック | 情報パネルの「映像」「音声」に出す。ファイルのヘッダ（MP4/MOV は `stsd` のフォーマット、WebM は `CodecID`）から名前を引く（`videos::codecs`、コマンド `video_codecs`）。DB には持たず、パネルを開いたときにファイルから読む。ヘッダが読めなければ「不明」、音声トラックが無ければ「なし」。フレームレートは映像トラックの平均（MP4/MOV は `stts` と `mdhd`、WebM は `DefaultDuration`。断片化 MP4 や `DefaultDuration` が無い WebM は「不明」）。ビットレートはファイル全体の平均（容量 ÷ 再生時間。画面側で計算）で、トラック別は出さない |
| 再生 | ビューアの `<video>`（`features/videos/VideoView.tsx`）。Web ビューが読める形式だけ。再生できなければサムネイルと「既定のアプリで開く」 |
| CSP | `media-src 'self' asset: http://asset.localhost` を足した（`tauri.conf.json`。ユーザー承認済み） |
| 一覧 | サムネイルの右下に再生時間。ホバーのコマ送りは後回し |
| 似ている画像 | 対象外（`phash` なし） |

## サムネイルを設定する

一覧のサムネイルを、動画のコマの代わりに自分で選んだ画像にする（パッケージの絵を決めるイメージ）。対象は動画だけ。

| 論点 | 決定 |
|---|---|
| どこから | 画像ファイル（ファイルを選ぶダイアログ）、クリップボードの画像、ライブラリの画像（動画と画像を 1 つずつ選んで「選んだ画像を動画のサムネイルに」）、採用した子（親子の紐づけ。[LINKS.md](LINKS.md)） |
| 操作の場所 | 右クリックの「サムネイル」（動画を選んでいるときだけ出す）、メニューバーの 項目 → サムネイル（ライブラリが動画を使うときだけ）、詳細パネルの「サムネイル」の節（動画 1 件のとき）。使えないものは無効表示にして理由をツールチップに書く |
| 戻す | 「動画のコマに戻す」。取り込み時のコマを残しておくので、OS に作り直させない（無ければ作り直す）。設定した直後のトーストの「元に戻す」も同じ（前も設定した画像だったときは、前の画像は残していないので出さない） |
| 保存 | `thumbs/<id>_c<時刻>.jpg|png`（長辺 512px、透過があれば PNG）。設定のたびに名前を変え、一覧が古い画像をキャッシュから出さないようにする。前に設定した画像は消す。DB には印を持たず、名前で見分ける（`videos/thumb.rs` の `is_custom`、画面へは `Item.ownThumb`） |
| ライブラリの画像から | その画像のサムネイル（向きを反映済み、同じ 512px）を写す。元の画像を後で消しても、動画のサムネイルは残る |
| 別のライブラリへ・削除 | コピーでは設定した画像と取り込み時のコマの両方を運ぶ（`other_thumbs`）。完全に削除すると両方消す |
| 共有・書き出し | 共有の一覧は設定した画像を出す（`items.thumb` をそのまま使う）。書き出しはファイルだけで変わらない |

## 触るところ

- 拡張子：`videos::EXTS` と `lib/api.ts` の `VIDEO_EXTS`、`formats::SUPPORTED_EXTS`
- ビューアのキー：どこをクリックしたあとでも、Space・Enter・Esc は閉じる、矢印は前後の項目へ（ほかの種類と同じ）。プレーヤーの操作は K（再生 / 一時停止）、J / L（10 秒戻す / 進める）、, / .（一時停止中に 1 コマ）。YouTube と同じ割り当て。
  シークバーなどを操作するとプレーヤーにフォーカスが移り、そのままだと Space・矢印がプレーヤーに取られる（クリックの前後で Space の意味が変わる）ので、ポインタを離したらフォーカスを外す（`VideoView.tsx`）
- 範囲再生（Range）は asset プロトコルが受ける
- サムネイルの設定：`videos/thumb.rs`（`set_video_thumb` / `reset_video_thumb`）、`features/videos/VideoThumbField.tsx`（詳細パネル）、`commands.ts` の `item.thumb*`
