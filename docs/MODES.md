# モードを分ける：ストックとフォント

使っていて困っていること：

- フォントはモードが分かれているのに、「すべて」にもフォントが混ざって出る
- フォルダ・タグ・スマートフォルダが画像・ファイル・フォントで共通なので、フォントモードにフォントと関係の無いフォルダやタグが並ぶ
- フォントを「比べて選ぶ」ための分類（書体、和文／欧文）と、画像を「探して使う」ための分類（案件、用途）は、そもそも軸が違う

[ARCHITECTURE.md](ARCHITECTURE.md) の方針（使う場面が違うのでフォントだけモードにした。将来フォントを別アプリにする案もある）に沿って、
フォントを **完全に分ける**。

**実装済み**（下の「実装で決めたこと」も参照）。

## 決定

| 論点 | 決定 |
|---|---|
| モード | **［ストック｜フォント］** の 2 つ。ストックは画像・ファイル（今後の URL などもここ）、フォントはフォントだけ |
| ストックにフォントを出すか | **出さない**。今の「すべて」からフォントを外す |
| フォルダ・タグ・スマートフォルダ | **モードごとに別々に持つ**。ほかのモードのものは出さない |
| お気に入り・ピン留め・ゴミ箱・シェルフ | それぞれのモードの中だけで数え、表示する（シェルフはストックでは書き出し・まとめて出力、フォントでは比較に使う） |
| 両方の種類が入っている今のフォルダ・タグ | **同じ名前・同じ階層で両方のモードに作り、中身を種類ごとに振り分ける**。何も失わない |

## モードごとの中身

| | ストック | フォント |
|---|---|---|
| 一覧に出る種類 | 画像・ファイル | フォント |
| 種類の絞り込み | あり（画像／ファイル） | なし |
| 重複の候補 | あり（画像だけ） | なし |
| シェルフの操作 | 書き出し…、まとめて出力… | 比較する |
| 絞り込みの行 | [NAVIGATION.md](NAVIGATION.md) | [NAVIGATION.md](NAVIGATION.md) |
| 画面 | 今の一覧 | [FONT_UI.md](FONT_UI.md) |

- 切り替えはサイドバー上部の［ストック｜フォント］のセグメント（⌘1 ストック／⌘2 フォント）。件数はツールチップ。使う種類は設定の「種類」で選ぶ
- 使う種類が 1 つだけのライブラリ（フォントだけ、画像だけ）は、今どおり切り替えを出さない
- 取り込みは種類で振り分ける。フォントモードで画像をドロップしたときなどは、取り込んだ先のモードをトーストで知らせ、［開く］を付ける

## データ

- フォルダ・タグ・スマートフォルダの表に、どのモードのものかを持たせる（`mode`：`"stock"` / `"font"`）
- 1 つの項目に付けられるのは、その項目のモードのフォルダ・タグだけ。別のモードのフォルダへのドラッグは受け付けない
- ライブラリごとの設定（`lastMode`、サイドバーで隠した項目 `hidden:<mode>`）は、`all` を `stock` と読み替えて引き継ぐ
- ライブラリ間のコピー・移動、フォルダの共有、MCP の操作も、項目のモードのフォルダ・タグだけを扱う

## 移行（初回起動時に 1 回）

1. 今のフォルダ・タグ・スマートフォルダごとに、中身の種類を数える
2. 片方の種類だけなら、そのモードのものにする。空ならストックのものにする
3. 両方が入っていれば、もう片方のモードに **同じ名前・同じ親・同じ色** のものを作り、そちらの種類の中身を移す
   - フォルダの手動の並び順は、それぞれの中で今の順を保つ
   - スマートフォルダは条件の `kinds` で判断する（空なら両方に作る）
4. 作業台は、フォント以外をストックのシェルフ、フォントをフォントのシェルフへ移す
5. 移行の前に `library.db` のバックアップを取る（今の更新時と同じ仕組み）

## 実装で決めたこと

| 論点 | 決定 |
|---|---|
| フォルダの振り分け | フォルダの中身は **サブフォルダも含めて** 数える。フォントだけならフォントのもの、ほかだけならストックのもの、両方ならフォント側に双子を作る。空のフォルダは親に合わせる（最上位はストック）。フォントだけのサブフォルダは、親のフォント側の双子の下へ移る（id は保つ） |
| タグの振り分け | ゴミ箱の中の項目も含めて数える。双子はフォント側に作る（ストック側が元の id を保つ） |
| スマートフォルダの振り分け | 条件の `kinds` が空のものは、今フォントに当てはまるときだけフォント側に双子を作る（使わない双子を増やさない）。双子のタグはフォント側の双子に置き換える |
| シェルフ | `tray` テーブルのまま。モードの種類で問い合わせるので、移行は要らない |
| バックアップ | 今のコードに「更新時のバックアップ」の仕組みが無かったので、移行の直前に `VACUUM INTO` で `library.before-modes.db` を作る（既存のライブラリで 1 回だけ） |
| 別のモードのフォルダへドロップ | Finder からのドロップでは、フォルダのモードでないものは未分類のまま取り込む（そのモードの最上位にフォルダの構成を作る） |
| 同じ名前のタグを両方に付ける | 画像とフォントを一緒に選んで付けると、両方のモードに同じ名前のタグができる（項目ごとにそのモードのタグ） |
| MCP | フォルダとタグの一覧はフォント用を「（フォント用）」の見出しの後に出す。パスやタグ名はモードごとに引いて結果を合わせる。`create_folder` に `kind` |
| 古い版で開いたとき | タグの名前が両方のモードにあると、古い版は片方だけを使う。フォルダやスマートフォルダは両方のモードのものがまとめて出る（壊れない） |
| 移行前の取り消し記録 | Claude の変更の取り消し（changes）はタグの id で持つので、双子へ移ったフォントのタグは、移行前の変更を取り消しても外れない |
