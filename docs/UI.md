# 画面の原則：表示を切り替えても操作の位置を不必要に変えない

使っていて困っていること：

- フォントの「見本」から「リスト」へ切り替えると、見本の文字の行が消えてツールバーが 1 行縮み、下の操作がガクッと上がる
- グループ分けで「ファミリー」を選んだときだけ「まとめる／並べる」が出て、ほかを選ぶと消える。押そうとした場所に無い
- 開いている表示（ゴミ箱、重複の候補、スマートフォルダ、フォルダ）によって 2 段目の項目が増減し、「評価」の星の位置が毎回変わる

位置が変わると、手が覚えた場所を毎回探し直すことになる。よく使う操作ほど困る。

## 原則

タブ・フィルタ・表示（ビュー・モード・レイアウト・グループ分け）の切り替えなどを繰り返しても、主要な操作の位置やレイアウトが **不必要に変化しない** ようにする。

実現方法の例：

| 場面 | どうするか |
|---|---|
| 一時的に使えない操作 | 利用者がその操作の存在を知る必要があれば、消さずに **無効表示** にし、理由をツールチップに書く。不要な操作まで常に出して情報量を増やさない |
| ラベルが変わるボタンや状態表示（並び順、グループ分け、パターン） | `min-width` や表示領域の確保で、隣の操作を押し出さない。固定幅は手段の一つで、長いラベルや狭いウィンドウ幅を考慮する |
| ある選択の中の下位の選択肢 | 表示の切り替えでは、上位の選択で出し入れせず、少なければ 1 つのセグメントに並べ、多ければメニューにまとめる。設定ダイアログのように上位の選択に応じて下位の項目を切り替えるのが適切な場合は、依存関係に沿った動的 UI を許容する |
| ウインドウが狭くて入りきらない | **幅に応じて段階的に畳む**（下の「畳む順番」）。行を増やして下の内容を押し下げない。畳んでも、その操作は行の中の同じ場所に残す |
| その表示だけの操作（ゴミ箱を空にする、まとめて整理、しきい値など） | 「この表示の操作」の置き場所を決めてそこに置き、その領域の位置と高さを保つ |
| 入力欄の中の × などの小さなボタン | 使えないときは隠してよいが、場所は空けておく（`visibility: hidden`） |

**例外**：利用者が自分で開け閉めするもの（サイドバー、詳細パネルとそのタブ「情報｜シェルフ」）は動いてよい。ただし開け閉めは、その操作をしたときにだけ起こす。別の操作の結果として勝手に開かない。
ただ一つ、一覧からドラッグしているあいだだけは、置き場所を見せるためにシェルフを出す（詳細パネルが開いていればそのタブを、閉じていれば一覧の上に重ねて）。シェルフへ落として追加されたら、それは利用者がシェルフを使った操作なので、パネルを開いてシェルフのタブのままにする。それ以外（ほかの場所へ落とした、取り消した、何も追加されなかった）は元に戻し、選んでいたタブも変えない。空にしてもタブはシェルフのまま（[FONT_UI.md](FONT_UI.md)）。

内容（一覧の行、件数、見出し）が変わるのはかまわない。この原則が対象にするのは **操作の場所** だけ。

## 今のずれている箇所

直すときの対象。上から影響の大きい順。

| 箇所 | 今の動き | 直し方 |
|---|---|---|
| ~~見本の文字の行~~ | **直した**（[FONT_UI.md](FONT_UI.md)）。フォントモードではどのレイアウトでも出す | |
| ~~サムネイルの大きさ（フォント）~~ | **直した**。フォントモードでは見本の文字の行の右端に置き、見本では文字、グリッドではタイルの大きさを変える。「すべて」のリストで消えるのは残っている | |
| ~~グループ分け~~ | **直した**。セグメント（フォントは［なし｜書体｜言語｜評価｜タグ｜フォルダ］、ストックは［なし｜年月｜評価｜タグ｜フォルダ］）。ファミリーはグループ分けから外し、常に 1 行で ▸ で開く | |
| ~~2 段目の左側~~ | **直した**（[NAVIGATION.md](NAVIGATION.md)）。「評価」「種類」などの条件は常に出ている絞り込みの行へ移した。表示の行の左は、サブフォルダ・重複のしきい値・並べ替えの案内などその表示だけのもの | |
| ~~1 段目右の操作~~ | **直した**。「追加」「フォルダから追加」はツールバーから外してメニューバーの「ファイル」へ（主な動線はドラッグ&ドロップ、[MENUS.md](MENUS.md)）。残る「ゴミ箱を空にする」「まとめて整理」「読み込み直す」は帯の「この表示の操作」へ移した。1 段目はタイトル・件数・検索・詳細パネルだけになり、表示を移っても検索欄の幅が変わらない | |
| ~~並び順のラベル~~ | **直した**。ラベルの入れ物に `min-width`（7.75rem）を持たせ、「ファイルサイズ」を選んでも右の操作を押し出さない | |
| ~~種類の切り替え~~ | **直した**。絞り込みの行の「種類」にし、重複の候補では無効表示（画像だけが対象、とツールチップに書く） | |
| ~~検索欄の ×~~ | **直した**。文字が無いときも場所は空けておく | |
| ~~絞り込み条件の行~~ | **直した**（[NAVIGATION.md](NAVIGATION.md)）。絞り込みバーと「絞り込み中」の行を無くし、常に出ている 1 行の絞り込みの行にした。条件を付けても行は増えず、狭いときは横にスクロールする | |

サイドバーの項目がモードで違う（フォントモードでは「重複の候補」が無い）のは、モードが別の一覧なので対象外とする。並び順だけはモード間でそろえる。

## 決めたこと

| 論点 | 決定 |
|---|---|
| 「まとめる／並べる」の置き方 | ~~グループ分けのセグメントに 2 つとも入れる~~ → グループ分けから外し、ファミリーは常に 1 行にして ▸ で開く（[FONT_UI.md](FONT_UI.md)） |
| 表示ごとに変わる操作 | どの表示でも使う操作は同じ位置に置く（存在を知る必要があるものは、使えないときも無効表示で残す）。その表示だけの操作は「この表示の操作」の場所にまとめる |
| 詳細パネル（情報タブ）の並び | 名前の下に要点 1 行（サイズ・形式・再生時間）、その下に評価の星とお気に入り・ピン留め・シェルフ（アイコンのみ、ラベルはツールチップ。複数選択で混在のときは破線）を 1 行。続けて折りたためる節「整理（タグ・フォルダ）」「紐づけ」「メモ」「ファイル情報」。閉じた節は見出しの右に中身の要約を出す。開け閉めは利用者の操作のときだけで、`localStorage`（`inspector.section.<id>`）に覚える。既定は「整理」だけ開く（フォントは「ファイル情報」も開く）。複数選択では「メモ」「ファイル情報」は出さない（`components/Inspector.tsx`） |
| 原則の書き方 | 「位置を変えない」の一律の禁止ではなく、「不必要に変化させない」を原則とし、無効表示・幅・置き場所は実現方法の例とする（ui-platform のレビューを受けて、desktop-platform・ui-platform と同じ書き方にそろえた） |

## 操作の帯（ツールバー 2 段目）

絞り込みの条件・その表示だけの操作・この帯の操作・表示の操作を、**1 本の帯**にまとめる（[NAVIGATION.md](NAVIGATION.md)）。左から：

```text
絞り込み  [評価▾ タグ▾ …（横スクロール）]  [この表示の操作]  すべて解除 条件を保存 │ 並び順▾ ↕ グループ[…] 紐づけ[…] │ レイアウト[…] ⚙ －●＋
```

「この表示の操作」はその表示だけのもの：フォルダの「サブフォルダの内容も表示」、重複の候補の「似ている度合い」と「まとめて整理…」、ゴミ箱の「ゴミ箱を空にする」、この端末のフォントの「読み込み直す」。**追加はここに置かない**（ドラッグ&ドロップが主な動線で、メニューバーの「ファイル」から行う。[MENUS.md](MENUS.md)）。その表示の操作が 1 つあるときは、説明や件数より先に場所を取り、縮むのは説明のほう

- 条件の列は横スクロールする。**最初の条件の位置は、どの表示でも変わらない**。その表示だけの操作は条件の右に置くので、出入りしても右側は動かない
- 条件の列は狭くても 8rem は残す。その表示だけの操作のほうが先に縮み、中で横スクロールする

### 畳む順番

ウインドウではなく **ツールバーの幅**（コンテナクエリ）で決まる。よく使うものほど後に畳む。畳んでも行の中の place は変えない。

| ツールバーの幅 | 畳むもの |
|---|---|
| `@max-[96rem]`（1536） | サムネイルの大きさのスライダー（⚙ の中に同じものがある） |
| `@max-7xl`（1280） | 「絞り込み」の見出し、「紐づけ」「似ている度合い」のラベル |
| `@max-6xl`（1152） | 「すべて解除」「条件を保存」→ ⋯ のメニュー |
| `@max-5xl`（1024） | 紐づけ・レイアウト → ⚙ の中へ。この表示の操作はアイコンだけに。似ている度合い → セレクト |
| `@max-4xl`（896） | 並び順はアイコンだけに |
| `@max-2xl`（672） | グループ分け → セレクト（`@max-md` でアイコンだけに） |
| `@max-xl`（576） | 表示の操作が帯の 2 行目へ。タイトルと検索欄が縦に積まれるのと同じ閾値 |

グループ分けを最後まで残すのは、1 クリックで切り替えられる価値が高いため。紐づけとレイアウトは ⚙ の中に同じものを常に置いてあるので先に畳む。

**残っているずれ**：最小ウインドウ（900px、両パネル開）で「重複の候補」を開くと、「似ている度合い」が帯の 3 行目に回る。その幅では帯がすでに 2 行なので許容する。

## 色（ダーク）

今はダークのみ（ライトは未実装、[SETTINGS.md](SETTINGS.md)）。色は Apple HIG（Dark Mode・Color・Accessibility）、Material Design 3（Color roles・States・Segmented buttons）、WCAG 2.2 に合わせ、`src/index.css` の `@theme` に役割の名前で置く。部品は値を直接書かず、この名前を使う。ライトを作るときは値を差し替える。

| 役割 | 名前 | 値 | 使うところ |
|---|---|---|---|
| 静かな操作 | `ghost`（`hover` / `press`） | ふだんは面・枠なし、ホバーで白 10%、押している間は白 16% | ツールバー（並び順とその向き、追加とフォルダから追加も枠なし）・一覧の見出しのボタン・シェルフの操作。操作していないときは文字とアイコンだけにして、色の付いた状態（条件あり・押されている）を目立たせる |
| 操作の帯 | 帯は黒 18% で一段沈め、チップは白 8%（ホバー 12%） | 頭に「絞り込み」の見出し | 一覧を絞る条件と、その見え方を決める操作のまとまり。ツールバーの中でこの帯だけ面を持たせる。条件のあるチップは `tonal`、使えないチップは面を外して細い輪（白 8%） |
| 検索 | 枠なし、白 7% の面 | 入力中は青い枠 | macOS のツールバーの検索欄と同じ。ダイアログの入力欄は `edge` の枠のまま |
| セグメント | `track` / `thumb`（`chosen`） | 溝は黒 28%、選択中のつまみは白 20%＋影、文字は白 | 並べて 1 つ選ぶもの（サイドバー上部のストック／フォント・レイアウト・グループ分け・似ている度合い・背景の明暗など）。macOS のセグメントと同じ無彩色。選ばれていない項目は `fg`（85%） |
| まとまりの枠 | `frame` | 白 22%、面なし | 詳細パネルの操作（紐づけ・サムネイルの欄など） |
| 操作の面・枠 | `control` / `edge` | 白 8% / 白 34%（panel に対して 3:1） | ダイアログのボタン（主・副の区別のため）。入力欄とチェックボックスの枠は `edge`。ダイアログ・メニュー・区切り線は今までどおり `line` |
| 押されている・有効 | `tonal` / `on-tonal` | #344a73 / #d6e3ff（6.9:1） | オンのトグル（紐づけを開いている）、条件のある絞り込みのチップ |
| 白い文字が載る青 | `accent-fill` | #2f6fe0（白に対して 4.7:1） | 主ボタン、メニューのハイライト行、チェックボックス、日付の選択。`accent`（#4c8dff）は青い文字・線・印に使う |
| 無効 | `disabled:off`（`off` / `off-edge`） | 文字 白 50%（5:1）、枠 白 14% | 部品全体を不透明度で薄くしない。文字と枠を別々に下げる。静かな操作は無効でも枠を出さない |

- 見出しと操作の区別は、操作のほうを溝や枠に入れて付ける。「グループ」などの見出しは溝の外の `dim` の文字
- 状態は色だけで伝えない。押されているトグルはアイコンの向きも変える（`aria-pressed`）
- 例外：比べる画面の「明」の地の上の部品は、明るい地の色のまま（`CompareView.tsx`）

この原則は desktop-platform の [UI Standard](https://github.com/jazmf-dx/desktop-platform/blob/main/standards/ui.md) にも載せる（stockroom で直したら、そちらの「出どころ」をこのファイルから実装へ差し替える）。
