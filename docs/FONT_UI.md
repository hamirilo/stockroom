# フォントの画面：見本・グループ分け・シェルフ・比較

使っていて困っていること：

- 「見本」から「リスト」へ切り替えると見本の文字の行が消え、ツールバーがガクッと動く。見本とリストの違いも小さい
- グループ分けがドロップダウンで、選択中のコントラストが低い。「1件にまとめる」「ファミリー別に並べる」と「評価」「タグ」が
  同じ列に並び、何を選んでいるのか分かりにくい
- 「作業台」という名前と、フォルダと同じ見た目のサイドバーの項目では、何をする場所か伝わらない
- 選んだフォントを並べて比べる画面が無い
- 見本のパターンが似たものばかりで、違いが分かりにくい。記号のパターンは半角と全角が混ざっている
  （`0123456789 ¥$%&@#!?` は半角、`（）` は全角 U+FF08 / FF09、`「」` は和文の括弧）

**実装済み**（下の「実装で決めたこと」も参照）。あわせて決めたこと：モードの分離は [MODES.md](MODES.md)、サイドバーとツールバーの役割は [NAVIGATION.md](NAVIGATION.md)、
表示を切り替えても操作の位置を変えない原則は [UI.md](UI.md)。

## 決定

| 論点 | 決定 |
|---|---|
| 見本の文字の行 | **どのレイアウトでも常に出す**。入力した文字はグリッドにも使う |
| レイアウト | **［見本｜グリッド］**。リストは無くす（見本の文字を小さくすれば代わりになる） |
| グループ分け | **［なし｜書体｜言語｜評価｜タグ｜フォルダ］** のセグメント。太さ違いの扱いはグループ分けから外す |
| 太さ違い | **ファミリーは常に 1 行**。▸ で、その行の下に太さ違いを開く |
| 作業台 | 一覧の下に置く **「シェルフ」** にする。サイドバーからは外す |
| 比較 | フォントモードでは **シェルフ＝比較** の対象。最大 **8 件**（この端末のフォントも置ける。[SYSTEM_FONTS.md](SYSTEM_FONTS.md)） |
| 比較の見せ方 | **フォントを行に固定**（並べ方の切り替えは無い）。1 行目は英数、続けて和文を最大 2 行 |
| 見本のパターン | 「何を確かめるか」で見出しを付けて分け直す。数字・記号は半角と全角を別にする。**自分のパターンを保存できる** |

## 見本の文字の行（ツールバー 2 段目）

```text
Aa [見本の文字を入力（空欄なら各フォントの見本）      × | パターン かな ▾]  文字 − ━━●━━ + 36px
```

- フォントモードでは、レイアウトにかかわらず常に出す（[UI.md](UI.md)）
- × は文字があるときだけ見せるが、場所は空けておく
- 「パターン」ボタンに、今のパターンの名前を出す（「各フォントの見本」「かな」「自由入力」など）。幅は固定し、長い名前は省略する
- 右端のスライダーは同じ位置のまま、レイアウトで意味が変わる

| レイアウト | スライダー | 範囲 |
|---|---|---|
| 見本 | 見本の文字の大きさ | 12〜160px |
| グリッド | タイルの大きさ | 120〜320px |

  今ツールバー 4 段目の右端にある `ThumbSize` は、ここへ寄せる

## 見本のパターン

メニューは見出しで分け、各行にパターンの名前と、実際の文字列（と、確かめること）を出す。

| 見出し | パターン | 文字列（たたき台） | 確かめること |
|---|---|---|---|
| 自分のパターン | （保存したもの） | | |
| — | 各フォントの見本 | （フォントごと） | |
| 和文 | かな | `あさきゆめみし ぁっゃ がぱ アキヲヴ ァッ` | ふところ・小書き・濁点 |
| | 漢字 | `一二三 永東京 鬱薔薇驚` | 画数の少ない字と多い字 |
| | 本文 | `あのイーハトーヴォのすきとおった風、夏でも底に冷たさをもつ青いそら` | 長文の読みやすさ |
| | 見出し | `知らないと損する！3つのポイント` | 太さ・勢い |
| | 約物（全角） | `、。・ー〜「」『』（）【】！？` | 句読点と括弧の位置 |
| 欧文 | 英字 | `ABCDEFGHIJKLM abcdefghijklm` | |
| | 英文 | `The quick brown fox jumps over the lazy dog` | |
| | 紛らわしい字 | `Il1\| O0o rn m {}[]` | コード用フォントの判別 |
| 数字・記号 | 半角 | `0123456789 ()[]{}<>!?#$%&@+-=*/` | |
| | 全角 | `０１２３４５６７８９（）［］！？＃＄％＆＠` | |
| 混植 | 和欧混植 | `2026年10月14日（水）iPhoneを¥128,000で購入` | 和文・欧文・数字の釣り合い |

- **自分のパターン**：メニューの先頭。「今の文字を保存」で入力欄の文字を保存し、行の × で消す。名前は文字列の先頭 12 字
  （ライブラリごとの設定 `library.db` の `settings` に保存）
- 末尾に「足りないフォントは各フォントの見本で」の切り替え（今の `specimenFallback`）を残す
- 置き場所は今の `features/fonts/SpecimenControls.tsx` の `PRESETS`

## レイアウト

| レイアウト | 中身 |
|---|---|
| 見本 | 1 ファミリー 1 行。名前・スタイル・評価・書体などの行と、見本の文字 |
| グリッド | 1 ファミリー 1 枚のタイル。見本の文字（入力が無ければ「あ永A」／欧文は「Aa」）と名前、スタイル数のバッジ |

- `MODE_LAYOUTS.font` から `list` を外す。保存されていた `layout:font = "list"` は「見本」で開く

## グループ分け

```text
グループ [なし|書体|言語|評価|タグ|フォルダ]
```

- 選択中は塗り（アクセント色の背景・白文字）にする
- 見出しの順：

| グループ | 見出し |
|---|---|
| 書体 | `FONT_CATEGORIES` の順（明朝・セリフ、ゴシック・サンセリフ、丸ゴシック、スラブセリフ、筆書体、手書き、デザイン、未分類） |
| 言語 | `FONT_SCRIPTS` の順（日本語、欧文、中国語、韓国語、その他） |
| 評価 | ★5 から未評価まで |
| タグ | タグの並び順。複数のタグがあるものは各タグに出る。最後に「タグなし」 |
| フォルダ | サイドバーの順 |

- `GroupBy` から `familyOne` / `family` を外し、`category` / `script` を足す。保存されていた `familyOne` / `family` は「なし」で開く

## 太さ違い（ファミリー）

```text
── 明朝・セリフ ──────────────────────────
▸ Shippori Mincho   5 スタイル  Regular · ほか 4 個   永遠の青い空…
▾ Noto Serif JP     7 スタイル  Regular · ほか 6 個   永遠の青い空…
      Regular                                         永遠の青い空…
      Bold                                            永遠の青い空…
```

- 一覧は常にファミリー単位（今の「1件にまとめる」の振る舞い）。代表は Regular、操作はファミリー全部に効く
- スタイルが 2 つ以上ある行だけ ▸ を出す。▸ を押すと、その行のすぐ下に太さ違いを細い順に並べる。▸ の無い行も同じ幅を空けて名前の位置をそろえる
- 開いた太さ違いの行は、それぞれ 1 つのフォントとして選択・評価・シェルフへの追加ができる
- 開いた状態はセッションの間だけ覚える
- グリッドではファミリーの 1 枚だけを出す（開かない）

## シェルフ（今の作業台）

一覧の下に置く、畳めるトレイ。サイドバーの「作業台」は無くす。

```text
▾ シェルフ 5 / 8   B キー・ドラッグで追加。比べたいフォントを最大 8 件まで置いておけます      空にする  [比較する →]
[あ Noto Sans JP ×] [あ Shippori Mincho ×] [あ Zen Maru ×] [あ Dela Gothic ×] [Aa Playfair ×] [空き] [空き] [空き]
```

- 追加：B キー（もう一度で外す）、右クリック、詳細パネルのボタン、シェルフへのドラッグ。見本の行・グリッドのタイルにもホバーで出るボタン
- 畳むと 1 行（件数と操作だけ）。開閉は利用者が操作したときだけ変わる
- 開いたときの高さは上の端をドラッグで変えられる（ダブルクリックで 1 行に戻す。ウィンドウの高さの 45% まで）。2 行分以上の高さでは折り返して並べ、件数が多くても見渡せる。1 行のときは横にスクロール
- 一覧からドラッグしているあいだは、シェルフの縁を点線にして置ける場所だと示す。上に来たら「＋ N 件をシェルフに追加」を重ね、カーソルを「＋」（OS のコピーのカーソル）に、ドラッグの絵に緑の「＋」を付ける。フォルダへのドロップ（移動）と見分けられるように。すでにあるとき・8 件を超えるときはその旨を出す
- 追加したものはシェルフの末尾にスクロールして見せる。開いているシェルフへの追加はトーストを出さない（増えたものと件数が見える）。畳んでいるときだけ「シェルフを開く」付きのトーストを出す（[NOTIFICATIONS.md](NOTIFICATIONS.md)）
- モードごとに別のシェルフを持つ（[MODES.md](MODES.md)）

| モード | 上限 | 右端の操作 |
|---|---|---|
| フォント | 8 件。空きの枠を点線で出す。9 件目は追加せず「シェルフは 8 件までです。外してから追加してください」と知らせる | 空にする、比較する |
| ストック | 今の作業台と同じ（上限なし） | 空にする、書き出し…、まとめて出力… |

- 「空にする」はシェルフから外すだけで、中身は消えない（元に戻す可）。ライブラリごとに保存し、アプリを閉じても残る（今の `tray` テーブル）
- 名前は「シェルフ」。メニュー・ショートカット一覧・ツールチップの「作業台」もすべて置き換える
- ストックのシェルフでの並べ替え（手動の並び）は今の作業台と同じ

## 比較ビュー

シェルフの「比較する」で開く。一覧の場所に表示し、「一覧へ戻る」（と Esc）で戻る。

```text
← 一覧へ戻る  比較 5 / 8  あと 3 件置けます                         背景 [暗|明]  文字 −━●━+ 24px
1 行目 英数（A〜Z・数字・記号）  2〜3 行目の和文 (かな)(漢字)(見出し)(本文)(約物)(混植)  [自分の文字を足す]
┌──────────────────┬────────────────────────────────────────────────┐
│ Noto Sans JP   × │ ABCDEFGHIJKLMNOPQRSTUVWXYZ abcdefghijklmnopqrstuvwxyz 0123456789 !?&@#$%… │
│ ゴシック          │ あさきゆめみし ぁっゃ がぱ アキヲヴ  一二三 永東京 鬱薔薇驚  、。・ー〜「」… │
│ [Regular▾] ★★★★☆ │ 2026年10月14日（水）iPhoneを¥128,000で購入                                │
│ ♡ お気に入り      │                                                                            │
├──────────────────┼────────────────────────────────────────────────┤
│ Playfair Display │ ABCDEFGHIJKLMNOPQRSTUVWXYZ abcdefghijklmnopqrstuvwxyz                        │
│ セリフ（欧文）    │ 0123456789 !?&@#$%*()[]{}<>/+-=.,:;'"                                        │
└──────────────────┴────────────────────────────────────────────────┘
```

- **フォントを行に固定する**。並べ方の切り替えは無い
- 左の欄：名前、書体、比べる太さ（ファミリーのスタイルから選ぶ）、評価、お気に入り、×（比較とシェルフから外す）。お気に入りのフォントは左端に緑の線
- 右の見本（観点ごとの列には区切らない）

| フォント | 1 行目 | 2〜3 行目 |
|---|---|---|
| 和文フォント | 英数：`ABCDEFGHIJKLMNOPQRSTUVWXYZ abcdefghijklmnopqrstuvwxyz 0123456789 !?&@#$%*()[]{}<>/+-=`。1 行に収め、はみ出しは省略 | 選んだ和文の観点を区切らずに続けて流す。2 行を超える分は切る。自分の文字は先頭 |
| 欧文フォント | 英字：`ABCDEFGHIJKLMNOPQRSTUVWXYZ abcdefghijklmnopqrstuvwxyz` | 数字・記号：`0123456789 !?&@#$%*()[]{}<>/+-=.,:;'"`。**和文は出さない**。自分の文字が英数だけなら、その間に 1 行足す |

  - 和文フォントか欧文フォントかは、フォントの言語（`Item.fontScript`）で決める
  - 観点のまとまりには、ホバーで観点の名前を出す
- 和文の観点のチップ：かな・漢字・見出し・本文・約物・混植。初めはかな・漢字・約物・混植。英数はチップにせず「1 行目 英数」と固定で表示する
- 背景：暗／明。文字の大きさ：14〜72px（初期値 24px）
- 0 件のときは「比べるフォントがありません。一覧でフォントを選んで B キー、またはシェルフへドラッグしてください（最大 8 件）」

## 実装で決めたこと

| 論点 | 決定 |
|---|---|
| ファミリーの行をシェルフに置く | **代表（Regular）の 1 件** として置く。▸ で開いた太さ違いの行はそれぞれ 1 件。比較ビューの「比べる太さ」で、ファミリーのほかのスタイルに切り替えられる（その場だけ） |
| 開いた太さ違いの行の選択 | その行のフォントだけを選ぶ。ファミリーの行（とその範囲選択・見出しのクリック・範囲ドラッグ）はファミリー全部を選ぶ |
| グループ分けのタグ | ファミリーの行は、どれかのスタイルに付いたタグの区切りに出る。書体・言語・評価・フォルダは代表のもの |
| モードごとのシェルフ | 同じ `tray` テーブルをモードの種類で問い合わせて出す（[MODES.md](MODES.md) でストックにフォントが出なくなり、中身も分かれた）。「空にする」は今のモードのシェルフのものだけを外す |
| フォントのシェルフが 8 件を超えたとき | モードの分離の前に「すべて」で置いたフォントなどで超えることがある。比較は先頭の 8 件 |
| ストックのグループ分け | フォントと同じくセグメント［なし｜種類｜評価｜タグ｜フォルダ］にした（[UI.md](UI.md)） |
| ストックのシェルフの書き出し・まとめて出力 | シェルフのすべてを、シェルフの並びで（以前の「選択中ならその画像だけ」は、一覧の選択から右クリックで行う） |
| 見本の文字の行が狭いとき | ツールバーの幅が 768px を切るとパターンのボタンを狭め（「パターン」の語を外して名前だけ）、672px を切ると大きさのスライダーを外して − / + だけにする。入力欄の幅を残し、ほかの操作に重ならない |
| トースト | シェルフの上に出す（シェルフの操作に重ならないように） |
| 比較ビューの設定 | 背景・文字の大きさ・和文の観点・自分の文字はこの PC に覚える（`localStorage`） |
