# ブックマーク（URL）

ストックの種類 `bookmark`（`ItemKind` / `db::Kind::Bookmark`）。Web ページの URL を、画像・ファイルと同じフォルダ・タグで保管する。
リンク切れの確認だけは保留（下の「まだ決めていないこと」）。

## 決めたこと

| 論点 | 決定 |
|---|---|
| モード | ストック（`modeOf`）。画像・ファイルと同じフォルダ・タグに並べる |
| 通信の原則 | **外へ取りに行くのは拡張機能だけ。アプリは URL を取りに行かない**（docs/ROADMAP.md「アプリは URL を取りに行かない」のまま）。CSP・capabilities・待ち受けポートは変えない |
| 集める手段 | ① ブラウザ拡張（右クリック・ポップアップの「このページをブックマークに保存」）② URL を一覧に貼り付け（⌘V）③ 外部アプリ（Feedability の「リンクだけ送る」。`POST /bookmark` で送れる） |
| 拡張機能から | タイトル（`document.title`）・説明（`og:description`、無ければ `description`）・ファビコン（ページが示す一番大きいアイコン、無ければ `/favicon.ico`）・アイキャッチ（`og:image`、無ければ `twitter:image`）を、ブラウザ（Cookie・会社のプロキシ込み）が読んで送る。画像は拡張が PNG / JPEG に描き直して `data:` URL にする（ファビコン 64px、アイキャッチ 1024px まで）。取れなかった画像は付けずに保存する |
| 貼り付け・外部アプリから | 取得なしで登録する。名前は URL のホスト名（`www.` を除く）、サムネイルはカード。あとで拡張から同じページを保存しても、すでにあるので重複になるだけで、タイトルや画像は更新しない |
| データの形 | **列は足さない**（スキーマは変えない）。名前＝タイトル、`source_url`＝URL（詳細パネルでは「URL」）、メモ＝説明の初めの値、`body`＝タイトル・URL・説明（検索欄が見る）、`ext`＝`url` |
| 保存するファイル | インターネットショートカット（`<タイトル>.url`。`[InternetShortcut]` と `URL=`）。書き出し・フォルダの共有・ライブラリ間のコピーは、そのまま動く。`url` は取り込める拡張子にはしていない（`SUPPORTED_EXTS` に無い）ので、`.url` をドロップしても入らない |
| サムネイル | アイキャッチがあればそれ（大きければ 512px に縮める）。無ければ、ファビコン・タイトル・ホスト名を描いた正方形のカード（`bookmarks::card`。グリッドの中央切り取りで欠けないよう正方形） |
| 重複 | URL をそろえて比べる（`bookmarks::normalize_url`）：`http(s)` のみ、スキームとホストは小文字、ポート 80 / 443 は省く、`#` 以降・`utm_*`・`fbclid`・`gclid` などの追跡パラメータ・末尾の `/` は無視、ユーザー名やパスワードは捨てる。そろえた URL から `items.hash` を作る（`bookmarks::hash_of`。ほかの種類とは混ざらない）ので、取り込みの重複判定と同じ仕組みで効く。すでにあれば足さず、ゴミ箱なら戻し、タグを足し、フォルダは未分類のときだけ入れる（画像の保存と同じ） |
| 開く | 「既定のアプリで開く」（`item.open`）とビューアの「ブラウザで開く」は URL をブラウザで開く（`openSelection`。`http(s)` だけ） |
| 検索・絞り込み | 検索欄は本文（タイトル・URL・説明）を見るので、ドメインでも探せる。種類の絞り込みに「ブックマーク」が出る。MCP の `find_items` にも種類「ブックマーク」と取り込み元 URL が出る |
| モック | `src/dev/mockBackend.ts` に例と `create_bookmark` を足した |

## 触るところ

- Rust：`src-tauri/src/bookmarks/mod.rs`（URL のそろえ方・カード・`add`）、`bookmarks/commands.rs`（`create_bookmark`）、`webimport.rs`（`POST /bookmark`、本文は JSON で 16 MB まで）
- 画面：`src/features/bookmarks/`（`api.ts`・`actions.ts`・`BookmarkView.tsx`）、`Viewer.tsx`・`Grid.tsx`（ホスト名の印）・`Inspector.tsx`
- 拡張機能：`extension/shared.js`（`saveBookmark`）、`background.js`、`popup.*`
- `POST /bookmark` の本文：`{ url, title, description, favicon, image, folder, tags }`。`url` 以外は省ける。`favicon`・`image` は `data:image/…;base64,…`

## まだ決めていないこと

- **リンク切れの確認**（保留）：アプリは通信しないので、今の原則ではできない。拡張機能から確かめる（ページを開いたときに記録する等）か、手動の操作に限って通信を許すか
- **保存したあとの更新**：貼り付けで入れたものに、あとからタイトル・画像を付ける方法（同じページを拡張から保存したとき、既存の項目を更新するか）
- **ページの中身の保存**：本文を Markdown（`.md`）のテキスト項目として別に作るのが既存の仕組みに乗る。ブックマークとの関係（リンクで結ぶか、同じ項目か）
- **ブックマーク専用の絞り込み**：ドメインで絞る条件（今は検索欄の文字で探す）
- **URL の追加の入口**：貼り付け以外（メニューやダイアログ、ブラウザからのドラッグ）
