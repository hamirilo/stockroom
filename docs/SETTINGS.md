# 設定画面とライブラリごとの設定

使っていて困っていること：

- モード（画像／フォント）がアプリ全体で 1 つなので、ライブラリを切り替えてもモードが前のまま。
  画像のライブラリは画像モード、フォントのライブラリはフォントモードで開きたい
- サイドバーの固定項目（お気に入り・ピン留め・作業台など）は、ライブラリによっては使わない。ライブラリごとに隠したい

あわせて、あちこちに散っている設定（ブラウザ拡張の連携、アップデートの確認）を 1 つの設定画面にまとめる。

## 決定

| 論点 | 決定 |
|---|---|
| ライブラリごとのモード | **最後に開いていたモードを自動で記憶する** ＋ 設定で **使う種類** を選べる（1 種類ならモード切替を隠す） |
| サイドバーで隠した項目 | **表示だけ隠す**。B キーでお気に入りに追加などの操作はそのまま使える |
| ライブラリごとの設定の保存先 | **`library.db`**。ライブラリのフォルダごと持ち運べば設定も付いてくる |

## 設定の置き場所（3 層）

| 層 | 保存先 | 中身 |
|---|---|---|
| アプリ全体 | `settings.json`（`app_config_dir`、`commands.rs` の `Settings`） | 起動時に開くライブラリ、アップデートの自動確認、ブラウザ拡張、ライブラリ一覧 |
| ライブラリごと | `<name>.library/library.db` の `settings` テーブル（新規） | 使う種類、最後に開いていたモード、サイドバーで隠す項目 |
| 表示の好み | `localStorage`（今のまま） | レイアウト・グループ分け（モードごと）、サムネイルの大きさ、パネルの開閉など |

表示の好みはライブラリに付けない（どのライブラリでも同じ見た目のほうが迷わない）。
ライブラリに付けたくなったものだけ、あとから `settings` テーブルへ移す。

共有フォルダやクラウドの同期フォルダに置いたライブラリを、複数人・複数の PC で（1 台ずつ）使う場合、ライブラリごとの設定は全員に効く。
「このライブラリはフォント用」という性質の設定なので、それでよいと判断した。同時に開くことは想定しない（`library.lock` で確認を出す。docs/FEATURES.md の「バックアップ」）。

## ライブラリごとの設定

### データ

`library.db` に追加する。他のテーブルと同じく `CREATE TABLE IF NOT EXISTS` で作る（シェルフの `tray` と同じやり方）。

```sql
CREATE TABLE IF NOT EXISTS settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL  -- JSON
);
```

| key | value | 無いとき |
|---|---|---|
| `modes` | 使う種類 `["image","font"]` | すべての種類（`MODES`） |
| `lastMode` | 最後に開いていたモード `"stock"` / `"font"` | 下の「開くときのモード」で決める |
| `hidden:<mode>` | そのモード（`stock` / `font`）のサイドバーで隠す項目 `["pinned","untagged"]` | 何も隠さない |
| `specimenPatterns` | フォントの見本の「自分のパターン」（新しい順、20 個まで）`["永遠の青い空", …]` | 無し |

モードを「すべて」と「フォント」の 2 つにしたとき（画像・ファイルは「すべて」の中の種類の絞り込みへ。docs/ARCHITECTURE.md）の読み替え：

- `lastMode` が `"image"` / `"file"`：「すべて」をその種類に絞って開き、`lastMode` を `"all"` で保存し直す
- `hidden:all` が無ければ、`hidden:<最後に開いていた画像・ファイルのモード>`、`hidden:image`、`hidden:file` の順に、あるものを使う。
  隠す項目を変えたときに `hidden:all` として保存される
- 古い版で開き直すと、`lastMode: "all"` のライブラリは「すべて」で開く（壊れない）

モードを［ストック｜フォント］に分けたとき（docs/MODES.md）の読み替え：

- `lastMode` が `"all"`：ストックで開く（モードを切り替えたときに `"stock"` で保存される）
- `hidden:stock` が無ければ `hidden:all`（無ければ上の画像・ファイルのモードのもの）を使う。アプリ全体の `sidebarHidden` も `all` をストックとして読む
- 古い版で開き直すと、`lastMode: "stock"` は知らないモードなので読み飛ばされ、件数で決まる（壊れない）

- 値は JSON。項目を増やしても列を足さずに済む
- 知らないキーや、知らない種類・項目の ID は読み飛ばす（古い版で開いても壊れない）
- コマンド：`get_library_settings() -> { [key]: JSON }`、`set_library_setting(key, value)`。
  `value` が `null` ならその行を消す

フロントエンドは `setLibrary` でライブラリを開くときに読み込み、`store` に `librarySettings` として持つ。

### 使う種類とモード

**開くときのモード**（`setLibrary` で決める）

1. `lastMode` があって、モード切替に出るもの（下）ならそれ
2. 無ければ、フォントの件数（`Counts.kinds`）が画像・ファイル・テキストを合わせたより多ければフォント
3. それ以外はストック（フォントだけを使うライブラリはフォント）

今ある `localStorage` の `mode` キーは使わなくなる（ライブラリを開いていないときのウェルカム画面ではモードを使わない）。

**モードを切り替えたとき**：`setMode` で `lastMode` を保存する。

**モード切替（`ModeSwitch`）**

- 「ストック」と「フォント」。フォントをほかの種類と使うときだけ出す（フォントだけならフォント、フォントを使わないならストックだけで、切替は隠す）
- ストックには使う種類（画像・ファイル・テキスト）だけが出て、ツールバーの種類のチップも使う種類だけ（2 種類以上のとき）
- ショートカット ⌘1 ストック / ⌘2 フォント（`MODES` の並び）。出ていないモードのキーは何もしない
- サイドバーの一番上。ライブラリの切り替え（`LibrarySwitcher`）は頻度が低いので一番下に置く

**使っていない種類のファイルを取り込んだとき**

取り込みは止めない（種類は中身で決まる）。取り込み後のトーストで知らせる：

> フォント 3 件を取り込みました。このライブラリでは使っていない種類です。［フォントも使う］

ライブラリ間のコピー・移動（`transfer.rs`）でも、コピー先で使っていない種類があれば同じように知らせる。

**使う種類から外したとき**

その種類のアイテムは消さない。件数が 1 件以上あれば、設定画面のチェックの横に「（123 件）」と出し、
外すときに「一覧に出なくなります。アイテムは消えません」と添える。

### サイドバーの項目

モードごとに隠せる（ストックではピン留めを使い、フォントモードでは使わない、といった使い分けができる）。

| ID | 項目 | 隠せるか | 備考 |
|---|---|---|---|
| `all` | すべて | × | 開いたときの表示先 |
| `unfiled` | 未分類 | ○ | |
| `untagged` | タグなし | ○ | |
| `favorites` | お気に入り | ○ | |
| `pinned` | ピン留め | ○ | |
| `similar` | 重複の候補 | ○ | ストックのみ（画像を使うライブラリ） |
| `trash` | ゴミ箱 | × | 削除したものの行き先が見えなくなるため |
| `section:folders` | フォルダ（節ごと） | ○ | |
| `section:smart` | スマートフォルダ（節ごと） | ○ | |
| `section:tags` | タグ（節ごと） | ○ | |

ファイルモード（`feat/file-mode`）で節が増えたら、ここに ID を足す。

作業台（`tray`）はサイドバーから外し、一覧の下のシェルフにした（docs/FONT_UI.md）。前の版で隠していた `tray` は読み飛ばす。

**隠し方・戻し方**

- 項目または節の見出しを右クリック →「サイドバーから隠す」
- 設定画面の「サイドバー」（アプリ全体、またはライブラリ）にチェックリストを置き、そこで戻す（隠すのもここでできる）
- 隠していることはサイドバーには出さない（下部の「n 項目を非表示（表示…）」は違和感があるので廃止）。戻すのは設定画面から

**隠した項目の振る舞い（表示だけ隠す）**

- 機能はそのまま：お気に入りやピン留めの切り替え、件数の集計（`get_counts`）は今までどおり
- いま開いている表示を隠したら「すべて」へ移る
- 隠した表示へ追加したときは、トーストに［お気に入りを開く］などを付けて、その表示へ行けるようにする
- 「フォルダ」の節を隠しても、フォルダ選び（Shift+D、`FolderPicker`）は使える

## 設定画面

- ⌘, で開くモーダル。入口はライブラリメニューの「設定…」と、macOS のアプリメニューの「設定…」
  （アプリメニューからは「アップデートを確認」と同じくイベント経由で開く）
- 左にページの一覧、右に中身。変更はその場で保存する（「保存」ボタンは置かない）
- 一覧は「アプリ全体」と「ライブラリ『名前』」の見出しで分ける（下の「サイドバーの全体設定と設定画面の整理」）

### 枠と行（どのツールでも同じ）

枠・行・スイッチは `components/SettingsFrame.tsx`、「アップデート」の節は `components/UpdateSection.tsx`。
workbench の各ツールにも同じファイルを置いている（desktop-platform UI §9）。

- 右側の上に開いているページの名前と閉じるボタン。ページの中は「見出し＋枠で囲んだ行」の節を並べる
- 行は左に名前と説明、右に操作。オン／オフはスイッチ（行のどこを押しても切り替わる）、少しの中から 1 つ選ぶものはラジオの行、
  一覧から選ぶもの（使う種類、サイドバーの項目）はチェックボックス
- ⌘, は最後に見ていたページで開く（ライブラリのページで、ライブラリを開いていなければ「一般」）。↑↓ でページを移る。
  Tab はダイアログの中だけを回り、閉じるとフォーカスは開く前の場所に戻る

### 一般（アプリ全体）

- 起動時：前回のライブラリを開く／ライブラリを選ぶ（`settings.json` に `startup: "last" | "choose"`）
- 「アップデート」の節（`UpdateSection`）：
  - アプリのアイコン・名前・バージョンと、確認の結果（確認しています… / 最新版です / v0.28.0 が使えます / 確認できませんでした）。
    ボタンは「アップデートを確認」、新しい版があるときは「更新内容」と「更新して再起動」
  - アップデートを自動で確認する（`autoUpdate: bool`、初期値オン）。オフなら `scheduleUpdateCheck` を動かさない
  - このバージョンの更新内容（GitHub のリリースのページ）
- このページを開いているあいだの確認は、結果をこの節に出す（トーストもダイアログも出さない）
- Windows のヘルプメニューの「Stockroom について」はこのページを開く

### アップデートの知らせ方

`lib/update.ts`。desktop-platform Distribution §4 に合わせている。

- 新しい版が見つかったら OS のダイアログで聞く。タイトルにアプリ名を入れる（macOS では太字の 1 行目、Windows ではウィンドウのタイトル）：

  ```
  Stockroom の新しいバージョンがあります
  v0.28.0 が使えます（今のバージョンは v0.27.0）。
  更新すると Stockroom が再起動します。
                       [更新内容を見る] [あとで] [更新して再起動]   ← macOS の並び
  [更新して再起動] [更新内容を見る] [あとで]                       ← Windows の並び
  ```
- 更新内容（リリースノート）はダイアログに載せない。「更新内容を見る」で GitHub のリリースのページ
  （`https://github.com/2204601/stockroom/releases/tag/v<version>`、Rust の `open_release_page`）を開く。
  ダイアログは閉じ、「あとで」と同じく設定の「アップデート」からいつでも更新できる
- 更新して起動し直した最初の 1 回だけ「Stockroom を v0.28.0 に更新しました［更新内容を見る］」のトーストを出す
  （前回のバージョンは `localStorage` の `lastVersion`）

## 他の作業との関係

- **ファイルモード（`feat/file-mode`）**：`MODES` に `"file"` を足す。DB のマイグレーションは無く、
  サイドバーの固定項目（`Sidebar` の `smart`）も触らない、と確認済み。こちらは種類を 2 つと決め打ちせず
  `MODES` の配列で扱う。⌘1〜⌘3 の一般化（`MODES[index]`）は向こうで入るので、使っていない種類を無視する条件だけ足す。
  向こうが先に main に入る見込みなので、実装はその後に main から始める

## サイドバーの全体設定と設定画面の整理

使っていて困っていること：

- サイドバーの非表示はライブラリごとにしか決められない。どのライブラリでも同じにしたいことが多い
- 設定画面で「一般」と「このライブラリ」が同列に並び、どこに保存される設定なのかわかりにくい
- サイドバーの固定項目と、設定の「連携」（ブラウザ拡張の手順）がごちゃごちゃしてきた

### 決定

| 論点 | 決定 |
|---|---|
| 全体設定を継承する単位 | **サイドバーの設定まるごと**（「すべて」「フォント」の両方）で 1 つのスイッチ。項目ごとの 3 状態は作らない |
| 右クリック「サイドバーから隠す」の書き込み先 | **いま効いている側**。全体に従うライブラリなら全体へ。トーストで「すべてのライブラリで隠しました」「このライブラリで隠しました」と効いた範囲を出し、［元に戻す］を付ける |
| 設定画面の左の一覧 | **見出しで 2 つに分ける**（アプリ全体／ライブラリ「名前」） |
| サイドバーの固定項目 | 3 つに分けて細い線で区切る。~~片付け（重複の候補・ゴミ箱）は一番下に固定~~ → 印の下に枠で囲んで置き、その下にフォルダ・スマートフォルダ・タグ（[NAVIGATION.md](NAVIGATION.md)）。件数 0 の表示は今のまま |
| ブラウザ拡張のページ | 用意・接続が済んでいれば手順を状態表示 1 枚に畳む |

### データ

| 層 | 保存先 | キー | 無いとき |
|---|---|---|---|
| アプリ全体 | `settings.json` | `sidebarHidden: { all: [...], font: [...] }` | 何も隠さない |
| ライブラリ | `library.db` の `settings` | `sidebar: "own"` / `"app"` | 下の「移行」 |
| ライブラリ | 同上 | `hidden:<mode>`（今のまま） | `sidebar: "own"` のときだけ使う |

- 「このライブラリだけの設定」に切り替えたとき、`hidden:<mode>` が空ならその時点の全体の値を写して編集を始める
- 全体に戻しても `hidden:<mode>` は消さない（また個別にすると前の値に戻る）
- **移行**：`sidebar` キーが無く、`hidden:*` に何か入っているライブラリは `"own"` として扱う（今の見た目を変えない）。
  何も隠していないライブラリは全体に従う。切り替えたら `"own"` / `"app"` を保存する
- フロントエンドは起動時に `settings.json` を読んで `store.appSettings` に持つ。
  いま効いている側は `sidebarScope`、その非表示は `sidebarHidden`（`store.ts`）
- 全体設定は PC ごと。共有フォルダのライブラリで全体に従うと、PC によって見た目が変わる。
  持ち運ぶ前提のライブラリは「このライブラリだけの設定」にする
- 継承の仕組み（`own` かどうか＋全体の値）は、フォント見本の既定などあとで足す設定にも使い回せる形にしておく

### 設定画面

```
設定
 アプリ全体
   一般              起動したとき・アップデート
   サイドバー         全体の既定（「すべて」「フォント」の 2 列はいつも出す）
   ブラウザ拡張        今の「連携」の上半分
   Claude            今の「連携」の下半分
 ─────────
 ライブラリ「名前」     見出しの下に小さく「このライブラリに保存」
   概要              名前・場所・件数・使う種類・別のライブラリへ移す
   サイドバー         ◉ アプリ全体の設定を使う ○ このライブラリだけの設定
   フォルダの共有      共有中のフォルダの一覧（URL・ダウンロードの可否・停止）。共有はフォルダの右クリック「共有…」から
```

- ライブラリを開いていないときは「ライブラリ」の見出しごと出さない
- ライブラリのサイドバー：全体に従うときはチェックの一覧を全体の値で薄く出し（触れない）、「アプリ全体の設定を開く」を添える。
  列はそのライブラリの使う種類のモードだけ
- `SettingsTab` は `general` / `sidebar` / `extension` / `claude` / `library` / `librarySidebar` / `libraryShare`
- ブラウザ拡張：用意済みかつ接続済みなら、手順 1・2 を「用意済み・接続済み｜もう一度用意する」の状態表示にし、
  手順は「設定の手順を表示」で開く。「使い方」はいつも出す

### サイドバーの固定項目

```
すべて / 未分類 / タグなし
──
お気に入り / ピン留め          ← 作業台は一覧の下のシェルフへ（docs/FONT_UI.md）
［重複の候補 / ゴミ箱］        ← 枠で囲む（docs/NAVIGATION.md）
```
