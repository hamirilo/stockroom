# 画像の比較：シェルフの画像を並べ、一緒に拡大して見比べる

フォントのシェルフには比較ビュー（[FONT_UI.md](FONT_UI.md)）があるが、ストックのシェルフは書き出し・まとめて出力の前に集めておく場所でしかなかった。
「書き出しの設定違い」「似た写真のどれがよいか」のように、画像を並べて同じところを見比べたい。

## 決めたこと

| 論点 | 決定 |
|---|---|
| 入口 | ストックのシェルフの「比較する」。フォントと同じ場所・同じ見た目（[UI.md](UI.md)：モードを切り替えても主要な操作の位置を変えない）。シェルフの右クリックにも |
| 対象 | シェルフの **画像だけ**、シェルフの並びで先頭の **12 件**。画像が無いときは「比較する」を無効表示にし、理由をツールチップに書く。画像以外が混ざっている・12 件を超えるときは見出しの行でその旨を出す |
| 表示する場所 | フォントの比較と同じく一覧の場所。「一覧へ戻る」と Esc で戻る。シェルフ・サイドバー・詳細パネルはそのまま |
| 並べ方 | すべてを 1 画面に収める。枠は同じ大きさで、列の数は画像がいちばん大きく見える数を自動で選ぶ（形の違う画像が混ざっていても）。並べ方の切り替えは作らない |
| 枠の中 | 画像全体を枠に収める（回転・反転を反映）。小さい画像も枠いっぱいまで拡大する。同じ構図の別サイズを、同じ見え方で並べるため。実際の大きさは下の行の「幅 × 高さ」で分かる |
| 拡大・移動 | **すべての画像で一緒に**。倍率は「全体を枠に収めたとき」に対する倍率（×1〜×32）、場所は画像の中の同じ割合の位置。大きさの違う画像でも同じところが出る |
| 操作 | Option / Ctrl ＋ホイール（トラックパッドのピンチ）でポインタの位置を中心に拡大・縮小。拡大中はドラッグ・ホイールで移動。クリックでその場所を ×4 に、拡大中のクリックで全体に戻る。⌘+ / ⌘- / ⌘0 と見出しの − ＋「全体」でも。ビューアの操作にそろえた |
| 画像の下 | 名前、お気に入り、×（比較とシェルフから外す）、評価、幅 × 高さ・形式・容量。フォントの比較の左の欄と同じ項目 |
| 背景 | 暗／明。この PC に覚える（`localStorage` の `compareImagesLight`） |
| 状態 | 拡大と場所は `store.compareLook`。メニューの「拡大」「縮小」（⌘+ / ⌘-）が比較中はここを変える（`commands.ts` の `zoom`）。比較を開くたびに全体に戻す |

## 作らなかったもの

- 2 枚を重ねて境目をスライドする比較、差分の表示：まず並べて同じところを見られれば足りるか、使ってから決める
- 画像ごとの拡大（連動を切る）：比べるための画面なので、連動だけにした
- 12 件を超える分のスクロール：1 画面に収めて見比べるのが目的。超える分はシェルフの並びを変えて入れ替える

## コード

- `components/ImageCompare.tsx`：比較ビュー。`columnsFor` が列の数、`place` が枠の中の位置と大きさを決める
- `components/Shelf.tsx`：「比較する」をモードに関わらず右端に置く
- `store.ts`：`comparing` はフォント・ストックの両方で使う。`compareLook` / `zoomLook` / `COMPARE_ZOOM`
