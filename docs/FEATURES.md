# 機能と使い方

## 機能

- **インポート**：ウィンドウへのドラッグ&ドロップ、「追加」ボタン、クリップボードから貼り付け（⌘V / Ctrl+V）
  - フォルダを取り込むと **フォルダ構造をそのまま再現**（同名フォルダは再利用）
  - サイドバーのフォルダに直接ドロップすると、そのフォルダへ入る
  - 同じ画像（SHA-256 一致）は重複としてスキップ。ゴミ箱にあるものは復元される（すでに別フォルダにある画像は移動しない）
  - 対応形式：JPEG / PNG / GIF / WebP / BMP / TIFF / SVG / HEIC・HEIF / AVIF、フォント（TTF / OTF / WOFF / WOFF2 / TTC / OTC）、ファイル（PDF / Word・Excel・PowerPoint（doc・docx / xls・xlsx / ppt・pptx）/ Pages・Numbers・Keynote）、テキスト（Markdown（md）/ テキスト（txt）/ CSV・TSV）
    - HEIC・AVIF は OS のデコーダで読む（macOS は標準対応。Windows は Microsoft Store の「HEIF 画像拡張機能」「AV1 Video Extension」が必要）
    - HEIC・TIFF は表示用に JPEG のコピーを `previews/` に作る（Windows の WebView が表示できないため）
- **テキスト**（docs/TEXT.md）：Markdown・テキスト・CSV / TSV をストックの種類「テキスト」として扱う
  - ビューアの［プレビュー｜編集］。プレビューは Markdown を整形（見出し・表・チェックリスト・コード）、CSV / TSV を表（先頭 2,000 行）、テキストはそのまま
  - 編集は自動で保存する（⌘S ですぐ保存、Esc で編集欄から出る）。広いウィンドウでは Markdown の編集の隣にプレビューが出る
  - **新規テキスト**（⌘N、ファイルメニュー）：開いているフォルダに「無題.md」を作り、すぐ書き始められる
  - 文字だけを一覧に貼り付けると（⌘V）、その文字のテキストができる（Excel のセルは TSV、`# ` で始まれば Markdown）
  - Shift_JIS の CSV も読み書きできる（元の文字コードと改行のまま保存。Shift_JIS で表せない文字を入れたら BOM 付き UTF-8 で保存）
  - 検索欄で本文も探す
- **ブラウザから保存**（Chrome / Edge の拡張機能）：Web ページの画像をライブラリへ。保存した画像には元のページの URL が付き、詳細パネルから開ける
  - 画像を右クリック →「Stockroom に保存」、Alt（Mac は Option）+右クリックですぐ保存
  - 「このページの画像を一覧して保存…」：ページ内の画像（srcset の大きい版、画像へのリンク、CSS の背景も）を大きさ・形式で絞り込んでまとめて保存
  - 「スクリーンショットを保存」：いまブラウザに見えている範囲を画像にして保存
  - 保存先のフォルダと付けるタグは拡張機能のアイコンから選ぶ
  - 使い始めるには：設定（⌘,）→「ブラウザ拡張」でオンにし、「拡張機能のフォルダを用意して表示」→ Chrome の `chrome://extensions` で「デベロッパー モード」をオン →「パッケージ化されていない拡張機能を読み込む」でそのフォルダを選ぶ（このフォルダから入れればそのまま接続される）
  - 別の場所から入れた拡張機能（別のパソコンからコピーしたもの、開発中の `extension/` など）は、拡張機能のアイコン →「アプリと接続」。アプリに確認が出るので、両方に出る 4 桁の番号が同じなら「許可する」
  - ほかのアプリ（Feedability）からも、同じ受付で記事を Markdown として保存できる。受け付けは設定（⌘,）→「ブラウザ拡張」のスイッチと同じ。初めて送るときにアプリの名前と 4 桁の番号の確認が出るので、相手のアプリに出ている番号と同じなら「許可する」（docs/FROM_APPS.md）
  - アプリは起動中だけ `127.0.0.1:41620` で受け付ける（このパソコンの中の、接続を許可した拡張機能だけ。Web ページからの接続は拒否）。「すべての拡張機能との接続を解除…」で許可を取り消せる。画像は拡張機能がブラウザの Cookie・プロキシ設定のままダウンロードして渡す
- **Claude から整理**（MCP）：Claude Code / Claude Desktop に、タグ付け・フォルダ分け・表示名の変更・メモを頼める（ファイル名から判断する、少ない枚数なら画像を見て判断する）
  - 使い始めるには：設定（⌘,）→「Claude」でオンにし、表示されるコマンド（Claude Code）か設定（Claude Desktop）を貼る
  - 削除はできない。Claude がした変更はトーストか、設定の「連携」の一覧から元に戻せる（その後に手で変えたものはそのまま）
  - アプリは起動中だけ `127.0.0.1:41621` で受け付ける（トークン必須。Web ページからの接続は拒否）。詳しくは [MCP.md](MCP.md)
- **フォルダの共有**（見るだけ）：同じ Wi-Fi・社内 LAN にいる人や自分のスマホが、ブラウザでフォルダを見られるようにする
  - フォルダを右クリック →「共有…」でオンにすると、URL と QR コードが出る。スマホはカメラで QR コードを読み、ほかの人には URL を送る
  - 見られるのは、そのフォルダとサブフォルダの中身（名前・サムネイル・画像、元のファイルのダウンロード）。上のフォルダやほかのフォルダは見られない。メモ・タグ・評価は見せない
  - ダウンロードはフォルダごとに止められる。オフにすると一覧と画像を見るだけになる
  - 共有中のフォルダはサイドバーに印が付き、設定（⌘,）→ ライブラリの「フォルダの共有」に一覧が出る（URL のコピー・停止・すべて停止）
  - 共有はライブラリに保存され、アプリを開いている間だけ見られる（閉じると見られなくなり、開くとまた同じ URL で見られる）。共有をオフにすると、その URL はすぐ使えなくなる
  - 共有中のフォルダがあるときだけ、ポート 41640 で LAN からの接続を受け付ける。URL に入っている推測できない文字列が鍵なので、URL を知っている人は同じネットワークから誰でも見られる。通信は暗号化されない（HTTP）
  - つながらないとき：見る側が同じネットワークにいるか（スマホは Wi-Fi で）。Windows はファイアウォールで「プライベート ネットワーク」を許可し、ネットワークの種類を「プライベート」にする。ゲスト用 Wi-Fi など端末どうしの通信を止めているネットワークでは見られない
- **種類の絞り込み**：ストックでは、絞り込みの行の「種類」で一覧を画像・ファイル・テキストに絞る。フォルダやタグを移っても絞り込みは残る（「すべて解除」では外れる）。使う種類が 1 つなら出ない
  - 画像だけに絞ると、縦横・画像サイズの絞り込みと画像サイズの並び替えが使える
  - 種類の絞り込みはスマートフォルダの条件にもなる（「画像だけ」「PDF だけ」のようなスマートフォルダが作れる）
- **モード**：サイドバー上部の切替（⌘1 ストック / ⌘2 フォント）。ストックは画像・ファイル・テキスト、フォントはフォントだけで、フォントは見本を並べて比べる専用の画面で見る。フォントをほかの種類と使うライブラリだけに出る。docs/MODES.md
  - **フォルダ・タグ・スマートフォルダはモードごとに別々**。お気に入り・ピン留め・ゴミ箱・シェルフも、それぞれのモードの中だけで数えて出す
  - フォルダにはそのモードのものしか入らない。画像とフォントを一緒に選んで同じ名前のタグを付けると、両方のモードに同じ名前のタグができる
  - 取り込んだものの一部がもう片方のモードに入ったら（フォントモードで画像をドロップしたときなど）、トーストで知らせて［開く］を付ける
  - レイアウト・グループ分けはモードごとに覚える（ストックは標準、フォントは見本が初期値）
    - 以前の版でフォントを「リスト」や「ファミリー」のグループ分けで見ていたときは、見本・グループ分けなし（ファミリーは常に 1 行）で開く
  - **分ける前のライブラリ**は、この版で初めて開いたときに 1 回だけ振り分ける。画像・ファイルとフォントの両方が入っていたフォルダ・タグ・スマートフォルダは、
    同じ名前・同じ階層・同じ色のものをフォント側にも作り、フォントをそちらへ移す（何も失わない）。その前の `library.db` は、ライブラリのフォルダに
    `library.before-modes.db` として残る（戻したいときは、アプリを閉じてこのファイルを `library.db` に置き換える）
  - 「すべて」モードがあった版のライブラリはストックで開く。画像・ファイルのモードがあった版で、そのモードのまま閉じたライブラリは、ストックをその種類に絞って開く
- **一覧**：サムネイルサイズ変更、範囲ドラッグ選択、仮想スクロール。ゴミ箱へ移動（⌘⌫）すると次の項目が選ばれ、ビューアを開いたままでも続けて削除できる
  - ツールバーの 2 段目の右側で、並び順・グループ分け・レイアウト・表示（サムネイルの大きさ、下に出す情報）を切り替える
  - レイアウト（画像）：標準（行の高さをそろえ、縦横比のまま並べる）／Pinterest風（列の幅をそろえ、縦に詰める）はツールバーのボタンで、グリッド・リストは表示メニュー（スライダーのアイコン）から切り替える
    - グリッド：縦に長いスクリーンショットや横長のパノラマが混ざっていても同じ大きさの枠に収まる
    - リスト：1 行ずつ詳しく表示
  - レイアウト（フォント）：［見本｜グリッド］のボタン。リストは無い（見本の文字を小さくすれば代わりになる）。docs/FONT_UI.md
    - **見本の文字の行**（ツールバー 2 段目）はどのレイアウトでも出す。入力した文字が全部のフォントに反映され（空欄なら各フォントの見本）、フォントに無い文字は赤い点線で示す。
      入力した文字の半分以上が無いフォント（英語フォントに日本語の文章など）は、そのフォントの見本で表示し「欧文見本」などの印を付ける（「パターン」のメニューの「足りないフォントは各フォントの見本で」で切り替え。ビューアは置き換えない）
    - 右端のスライダー（⌘+ / ⌘-）は、見本では文字の大きさ（12〜160px）、グリッドではタイルの大きさ（120〜320px）
    - 「パターン」のボタンに今のパターンの名前を出す。メニューは「何を確かめるか」の見出し（和文・欧文・数字・記号・混植）で分け、
      数字・記号は半角と全角を別にする。先頭は **自分のパターン**（「今の文字を保存」で入力欄の文字を保存、行の × で消す。ライブラリごと）
    - 見本：1 ファミリー 1 行。名前・スタイル・評価・書体などの行と、見本の文字（画面に見えている行のフォントだけを読み込む）
    - グリッド：1 ファミリー 1 枚のタイルに、見本の文字（入力が無ければ「あ永A」／欧文は「Aa」）をそのフォントで描き、名前とスタイル数を添える
  - **ファミリー**：フォントの一覧は常にファミリー単位（代表は Regular。操作はファミリー全部に効く）。スタイルが 2 つ以上ある行は ▸ で、
    その行のすぐ下に太さ違いを細い順に開き、それぞれ 1 つのフォントとして選択・評価・シェルフへの追加ができる（開いた状態はアプリを閉じるまで。グリッドでは開かない）
  - **この端末のフォント**（サイドバーの「見るもの」）：この端末にインストールされているフォントを、ライブラリに取り込まずに同じ見本・グリッド・ビューア・詳細で見られる。
    読み取り専用で、言語・書体・太さ・特徴・形式の絞り込み、名前の検索、書体・言語のグループ分け、Finder / エクスプローラで表示が使える。
    評価・タグ・フォルダ・メモ・書き出しはライブラリのフォントだけ（無効表示）。初めて開いたときに OS のフォントのフォルダを読み、
    次からは変わったファイルだけを読み直す（ツールバーの「読み込み直す」で、インストール・削除したフォントを反映）。docs/SYSTEM_FONTS.md
    - **シェルフ・比較**にも置け、ライブラリのフォントと並べて比べられる（ドラッグはシェルフへだけ）。シェルフはライブラリに残るので、
      別の端末で開いてそのフォントが無ければ名前だけを取り消し線で出す
    - ライブラリと端末に同じフォント（PostScript 名が同じもの）があれば、ライブラリ側に「インストール済み」、端末側に「ライブラリにある」の印が付く
  - サムネイルの下に出す情報（名前・画像サイズ・評価・形式と容量）を切り替え
  - **グループ分け**：ツールバーのセグメントで 1 クリック（選択中は塗り）。ストックは［なし｜種類｜年｜月｜評価｜タグ｜フォルダ］、フォントは［なし｜書体｜言語｜年｜月｜評価｜タグ｜フォルダ］。
    年・月は追加日（取り込んだ日）で分け、新しい区切りが上（この端末のフォントには使えない）。評価は ★5〜未評価、タグは複数タグのものを各タグに表示（ファミリーはどれかのスタイルに付いたタグに出る）、フォルダは「すべて」やサブフォルダ表示で便利。区切りの見出しをクリックするとその区切りをまとめて選択
  - 並び替え：追加日・名前・ファイルサイズ・画像サイズ・評価・**手動**（フォルダ内でドラッグして並べ替え）
  - 「サブフォルダの内容も表示」でフォルダ配下をまとめて表示
- **整理**：入れ子フォルダ（1 枚は 1 つのフォルダにだけ入る。複数の分類にはタグを使う）、タグ（補完付き）、メモ、**★評価（0〜5）**
  - **お気に入り**（F、サムネイルのハート）とは別に **ピン留め**（P）があり、ピン留めした画像はどの一覧でも先頭に表示される。サイドバーの「お気に入り」「ピン留め」でまとめて見られる
  - キー・メニュー・ツールバーで評価・お気に入り・ピン留め・回転をすると、画面の下に何をしたか（「★★★☆☆ 評価 3　2 件」など）が少しのあいだ出て、変わったサムネイルが一瞬光る（ハートや星を直接クリックしたときは出さない）
  - フォルダ・スマートフォルダ・タグに **色** を付けられる（サイドバーで右クリック → 色の行から選ぶ。9 色）
  - フォルダの順番は自由に変えられる（行の上端・下端へドロップ、⌘[ / ⌘]）。右クリックで名前順に戻す
  - サイドバーのフォルダは ⇧+クリック（範囲）・⌘+クリック（1 つずつ）で複数選び、まとめてドラッグして移動・並べ替えできる
  - タグのコピー／貼り付け（⌘⇧C / ⌘⇧V）
  - 画像をサイドバーのフォルダへドラッグ、または **フォルダ移動ダイアログ**（⌘⇧J：検索・新規作成）
  - Shift+D で直前に使ったフォルダへ移動、「選択から新規フォルダ」
- **場所**：サイドバーは「どこを見るか」を 1 つ選ぶ場所。上から すべて（フォントモードは「すべてのフォント」）・未分類・タグなし／お気に入り・ピン留め／
  整理（重複の候補・ゴミ箱、枠で囲む）／フォルダ・スマートフォルダ・タグ。タグもフォルダと同じく、押すとそのタグの一覧を開く（docs/NAVIGATION.md）
- **検索・絞り込み**：名前・メモ・タグ名・フォントのファミリー名・テキストの本文を検索（`-語` で除外、`A OR B` / `A || B`、`( )`、`"語句"`）
  - **絞り込みの行**（ツールバー 3 段目、常に出ている）：ストックは 評価・タグ・種類・形式・画像サイズ・追加日・容量、フォントは 評価・タグ・言語・書体・太さ・特徴・形式・追加日。
    丸いボタンを押すとメニューが開き、選択肢ごとに **ほかの条件を付けたままの件数** が出る。使っている条件は塗りで値を出し、× でその条件だけ外せる。
    1 つの条件の中は「いずれか」（タグはメニューで「すべて」にも切り替え）、条件どうしは「すべて」。⌘⇧F で行へフォーカス
  - 絞り込み中はタイトルの件数が「5 / 13 件」になる。右端の「すべて解除」で検索と条件をまとめて外せる（場所を移ると自動で解除。ストックの種類だけは残る）
  - **スマートフォルダ**：絞り込みの行の「条件を保存」で今の条件（検索・タグ・評価・絞り込み）を保存すると、当てはまるものが自動で集まる。
    開くと条件が絞り込みの行に出て、「条件を編集」（または右クリック →「条件を編集」）で変更
- **ビューア**：拡大縮小（⌘+ / ⌘- / ⌥・Ctrl+ホイール / ピンチ）、実寸 ⌘0、全体 ⌘9、ドラッグでスクロール
  - 詳細パネル（I）で名前・サイズ・タグ・フォルダ・メモを確認し、評価・お気に入り・ピン留めを変更。下部のサムネイル（T）で前後の画像へ移動。1〜5 / F / P のキーも一覧と同じ
- **重複の整理**：サイドバーの「重複の候補」で、見た目が似ている画像をグループにして並べる（類似ハッシュ。完全一致は取り込み時に除外済み）
  - 「似ている度合い」を 3 段階で切り替え：**ほぼ同じ**（リサイズ・再保存程度）／**似ている**（標準）／**やや似ている**（無関係な画像も混ざる）
  - 各画像に「残す」「ゴミ箱へ」を表示し、「これを残す」で残す 1 枚を選べる（初期値は最高画質）
  - 「整理…」を押すと確認ダイアログで、残す／捨てる画像と、残す 1 枚へ引き継ぐタグ・評価・フォルダ（未分類のときだけ）を事前に確認できる。実行後は元に戻せる（引き継いだタグ・評価・フォルダも元に戻る）
  - グループ見出しの「重複ではない」で候補から外せる。ツールバーの「すべて解除」で戻せる
- **フォントの絞り込み**：フォントモードでは絞り込みの行に **言語**（日本語・欧文・中国語・韓国語・その他）、**書体**（明朝・セリフ／ゴシック・サンセリフ／丸ゴシック／スラブセリフ／筆書体／手書き／デザイン／未分類）、**太さ**（細い Thin–Light 〜399／標準 Regular–Medium 400〜549／太い SemiBold–Bold 550〜749／極太 ExtraBold–Black 750〜。メニューにはウェイト名を添える）、**特徴**（等幅／プログラミング向け／可変フォント／イタリック・斜体）が並ぶ。メニューには 0 件の項目も出す。同じ条件の中は「どれか」、条件どうしは「すべて」。スマートフォルダの条件にもなる
  - 言語は含まれる文字から判定。書体はフォント名（「明朝」「Gothic」「Rounded」「Slab」「楷書」「手書き」など）とフォント内の分類情報から自動で判定し、分からないものは「未分類」。詳細パネルの「書体」で選び直せる（複数のフォントを選んでまとめて設定も可）
  - 太さはフォントのウェイト（100〜900）。可変フォントは wght 軸がまたがる範囲すべてに数える
  - 特徴は自動で判定：等幅はフォントの指定か欧文字の送り幅が揃っていること、プログラミング向けは等幅のうち名前（Code・Mono 系の有名なもの）か「半角の 2 倍が全角」の送り幅かスラッシュ付きゼロ（zero 機能）を持つもの、可変フォントは可変軸があるもの、イタリック・斜体はフォントの指定
- **ファイル**（PDF・オフィス文書）：取り込んで、タグ・フォルダ・評価・メモで整理する。編集や中身の検索はしない
  - サムネイルは 1 ページ目。macOS は Quick Look、Windows は PDF だけ OS の PDF 描画で作る。作れないときはファイルの中に保存されたプレビュー（Pages / Numbers / Keynote、サムネイル付きで保存した Office 文書）、それも無ければ種類のカード（「XLSX」など）
  - ビューアでは PDF をそのまま読める。オフィス文書はサムネイルと「既定のアプリで開く」
  - 拡張子が .pdf でも中身が PDF でないもの（Web ページなど）は取り込まない（ビューアで中のスクリプトが動かないように）
  - パッケージ形式（フォルダ）で保存された古い Pages / Numbers / Keynote は取り込めない
- **フォント**：見本（"Aa" と、含まれる文字に合わせて「あア永」か "ABC abc 123"）を描いたサムネイルで一覧に並ぶ
  - ビューアで、入力した文字を好きな大きさで試せる（12〜200px、小さいサイズの見本も表示）。フォントに無い文字は赤い点線付きで示す（システムのフォントで代わりに表示されるため）。含まれる文字の一覧（先頭 3000 字まで）
  - ファミリー名でも検索できる。太さごとに別ファイルのフォント（Light / Regular / Bold …）は 1 行にまとまり、▸ で開いて見られる。幅違い（Compressed / Condensed / Extended / Wide など）は別ファミリーになる（「ヒカリ角ゴ Compressed」）。ファミリー名に太さが入ったフォント（「MOBO-Bold」「〜ボールド」）も、太さを取り除いてまとめる
  - 詳細パネルにファミリー・スタイルと太さ・文字数・製作者・版。可変フォントは軸（太さ 100〜900 など）と名前付きスタイルの数、TTC / OTC は中のフォントの一覧
  - TTC / OTC は 1 ファイル = 1 件。ビューアで中のフォント（W3 / W6 など）を切り替えて見る
  - 画素のサイズは無いので、縦長／横長・画像サイズの絞り込みと重複の候補には出ない。回転もできない
- **回転・反転**：右クリック、⌘⇧L / ⌘⇧R、ビューアのボタンで、90° 回転・左右反転・上下反転・元の向きに戻す
  - 元のファイルは書き換えない（向きだけを記録して、サムネイルとビューアに反映）。⌘C・ドラッグ・書き出しは今のところ元の向きのまま
- **持ち出し**：⌘C でクリップボードへ（ファイル＋画像データ）、ウィンドウの外へドラッグして他のアプリへ、既定のアプリで開く、フォルダへ書き出し。「ファイル」→「ライブラリ全体を書き出し…」で、ゴミ箱以外のすべてを `<ライブラリ名>/ストック/<フォルダ>/…` のようにフォルダ構成どおりにコピーする（バックアップとは別。[EXPORT.md](EXPORT.md)）
- **シェルフ**：詳細パネルのタブ（［情報｜シェルフ］）。比べたいフォント・画像や、まとめて出力・書き出しの前の画像を一時的に置いておく（以前の「作業台」。docs/FONT_UI.md）
  - B キー（もう一度で外す）、右クリック →「シェルフに追加」、詳細パネルのボタン、シェルフへのドラッグ、フォントの見本の行・タイルのホバーのボタンで追加
  - タブは自分で押したとき（⌘I で情報、⌘⌥3 でシェルフ）だけ変わる。一覧からドラッグしているあいだだけシェルフを出し、終われば戻す（パネルを閉じていれば一覧の右に重ねて出す）
  - 並びは入れた順に縦に並ぶ。シェルフの中で上下にドラッグして並べ替えられる。クリックで一覧のその項目を選ぶ
  - モードごとに別のシェルフ
    - フォント：**8 件まで**（空きの枠を点線で出す。9 件目は知らせて追加しない）。ファミリーの行は代表の 1 件として置き、▸ で開いた太さ違いはそれぞれ置ける。操作は「空にする」「比較する」
    - ストック：上限なし。操作は「空にする」「書き出し…」「まとめて出力…」（シェルフのすべてが対象、シェルフの並びのまま）「比較する」（画像だけ）
  - 「空にする」はシェルフから外すだけで、中身は消えない（元に戻す可）。ライブラリごとに保存され、アプリを閉じても残る
  - 右クリックで「別のライブラリへ…」も
- **比較**：フォントのシェルフの「比較する」で、一覧の場所に並べて比べる。「一覧へ戻る」か Esc で戻る
  - フォントを行に固定。左に名前・書体・比べる太さ（ファミリーのスタイルから選ぶ）・評価・お気に入り（お気に入りは左端に緑の線）・×（シェルフから外す）
  - 和文フォントは 1 行目に英数（1 行に収め、はみ出しは省略）、続けて選んだ観点（かな・漢字・見出し・本文・約物・混植。初めはかな・漢字・約物・混植）を区切らずに 2 行まで。
    「自分の文字を足す」の文字は先頭。観点のまとまりにはホバーで観点の名前を出す
  - 欧文フォントは英字と数字・記号の 2 行で、和文は出さない（自分の文字が英数だけなら間に 1 行足す）
  - 背景は暗／明、文字の大きさは 14〜72px（初期値 24px）
- **画像の比較**：ストックのシェルフの「比較する」で、シェルフの画像（先頭の 12 件）を一覧の場所に並べる（docs/COMPARE.md）
  - 同じ大きさの枠にすべてを 1 画面で。列の数は自動
  - 拡大・移動はすべての画像で一緒に、画像の中の同じ場所へ。Option / Ctrl ＋ホイール（ピンチ）で拡大、ドラッグ・ホイールで移動、クリックで ×4 ／全体、⌘+ / ⌘- / ⌘0
  - 画像の下に名前・お気に入り・×（シェルフから外す）・評価・幅 × 高さ・形式・容量。背景は暗／明
- **まとめて出力**：選んだ画像を番号付きで 1 枚の画像（PNG / JPEG）か 1 つの HTML にまとめる。「この中でどれがいい？」と聞きたいときに、1 ファイルで渡せる
  - 右クリック →「まとめて出力…」、またはシェルフから。並びは一覧（シェルフからはシェルフ）の順
  - タイトル、番号（1, 2, 3 / A, B, C / なし）、画像の下の名前・サイズ・形式・容量、列の数（自動は 16:10 くらいになる列数）、画像の幅（1200〜3600px）、背景（白／黒）を選べ、プレビューで確認できる
  - 形の違う画像が混ざっても、同じ大きさの枠に全体が収まる（回転・反転を反映。フォントは見本の画像）
  - 「画像をコピー」でクリップボードへ（チャットやメールに貼り付け）、「保存…」でファイルに
  - HTML は画像を中に入れた 1 ファイル。画面の幅に合わせて並び、クリックで拡大（← → で前後）
- **ゴミ箱**：⌘⌫ / Delete で移動（元に戻す可）、復元・完全削除
- **ウィンドウ**：閉じたときの大きさ・位置・最大化を覚えていて、次はその状態で開く（そのディスプレイが無いときは位置だけ戻さない）
  - macOS はタイトルバーの帯を無くし、閉じる・最小化・拡大のボタンをサイドバーの上に重ねる。ツールバーの空いたところ・サイドバーの上端をつかんで移動、ダブルクリックで拡大。ウィンドウ枠やダイアログは OS の設定によらずダーク
  - macOS はサイドバーが半透明（Finder と同じ、後ろの画面がぼけて透ける）。ウィンドウが裏にあるときは不透明な灰色
- **二重起動しない**：起動中にもう一度開くと、新しく起動せずに今のウィンドウを前に出す（1 つのアプリで開けるライブラリは 1 つ。切り替えはメニューの「最近使ったライブラリ」かサイドバー下部）
- **OS の通知**：10 秒以上かかった取り込み・別のライブラリへのコピー／移動・書き出しが、ほかのアプリを使っている間に終わったら、OS の通知で知らせる
- **ログ**：警告・エラーをファイルに残す。ヘルプ →「ログを表示」（macOS は `~/Library/Logs/com.local.stockroom/`、Windows は `%LOCALAPPDATA%\com.local.stockroom\logs\`）。1 MB ごとに切り替え、古いものは 2 つまで残す

## ライブラリの構造

ライブラリは 1 つのフォルダで完結しているので、フォルダごとコピーすればバックアップ・別 PC への移動ができる。

```
MyPictures.library/
  library.db                 # SQLite（フォルダ・タグ・メモ・共有など）
  images/<id>/<元のファイル名>  # 取り込んだ画像のコピー
  thumbs/<id>.jpg|png        # 長辺 512px のサムネイル（透過画像は PNG）
  thumbs/<id>_o<反転><回転>.jpg|png  # 回転・反転した画像のサムネイル（元のサムネイルも残す）
  previews/<id>.pdf|.qlpreview/  # オフィス文書のビューア用（Windows は Office が作る PDF、macOS は Quick Look）
  previews/<id>.jpg          # HEIC・TIFF の表示用 JPEG（長辺 4096px まで）
  library.lock               # アプリで開いている間だけ（開いている PC の名前と、2 分ごとに更新する時刻）
```

## バックアップ

- **アプリを終了してから** `.library` フォルダごとコピーする。起動中は SQLite の作業ファイル（`library.db-wal` / `-shm`）に未反映の変更があるため、途中の状態を写してしまうことがある。
  アプリは終了するとき・ほかのライブラリに切り替えるときに、変更をすべて `library.db` に書き込んでから閉じる
- Time Machine はそのままで良い（APFS のスナップショットで一貫した状態が保存される）
- 取り込んだ画像のファイルは後から変わらないので、差分コピー（`rsync -a` / `robocopy /MIR` など）なら 2 回目以降は新しい画像だけが写る
- iCloud Drive・Dropbox・OneDrive などの同期フォルダは、**バックアップのコピーを置く先**として使うのが安全
- 同期フォルダの中のライブラリを複数の PC で使うときは：
  - **開くのは 1 台ずつ**。開いている間は `library.lock` があり、ほかの PC で開こうとすると「◯◯で開かれています」と確認が出る（同期が遅れて届かないこともあるので、頼り切らない）
  - **アプリを終了し、同期が終わってから**もう一方で開く
  - 元ファイルを「オンラインのみ」にしない（iCloud の「Mac ストレージを最適化」、OneDrive の「ファイル オンデマンド」は、ライブラリのフォルダを「常にこのデバイスに保持」に）
- NAS・社内のファイルサーバーに置いたライブラリを、**複数人で同時に開かない**（SQLite の WAL はネットワーク越しの同時アクセスに対応していない）
- 戻すとき：コピーしたフォルダを置き、「既存のライブラリを開く」で選ぶ
- フォルダの共有もライブラリに入っているので、コピーしたライブラリを開くと同じ URL で共有される（別の PC ならアドレスの部分は変わる）。止めたいときは設定の「フォルダの共有」から

最後に開いたライブラリのパスはアプリ設定（macOS: `~/Library/Application Support/com.local.stockroom/settings.json`）に保存される。
