# サイドバーとツールバーの役割：場所・絞り込み・表示

**実装済み**（下の「実装で決めたこと」）。ツールバーを 1 行にする変更（下の「ツールバー」、2026-11-14）は **未実装**。

使っていて困っていること：

- 絞り込みが 4 か所に散っている。サイドバーのタグ（とフォントの言語・書体・太さ・特徴）、ツールバー 2 段目の種類と評価、
  1 段目のボタンで開く絞り込みバー（形式・画像サイズ・追加日・容量）
- サイドバーのフォルダとタグは同じ見た目の行なのに、フォルダは「そこへ移る」、タグは「今の一覧に条件を重ねる」と働きが違う
- 条件を付けると「絞り込み中」の行が増え、一覧が下にずれる（[UI.md](UI.md) の原則に反する）

## 決定

役割を 3 つに分け、置き場所を 1 つずつにする。

| 役割 | 問い | 置き場所 | 選び方 |
|---|---|---|---|
| **場所** | どこを見るか | サイドバー | 1 つだけ選ぶ |
| **絞り込み** | その中をどう絞るか | ツールバーの絞り込みの行（「絞り込み」ボタンで開け閉めする） | 重ねて使える |
| **表示** | どう見せるか | ツールバーの「表示」ボタンのポップオーバー（大きさだけは常に出す） | 並び順・グループ・レイアウト・大きさ |

| 論点 | 決定 |
|---|---|
| サイドバーのタグ | **場所にする**。フォルダと同じく、押すとそのタグの一覧を開く（1 つだけ）。「フォルダの中をタグで絞る」「複数タグのいずれか／すべて」は絞り込みの行の「タグ」で行う |
| 絞り込みの置き場所 | ~~**常に出ている 1 行にまとめる**。絞り込みボタン（⌘⇧F で開くバー）と「絞り込み中」の行は無くす~~ → 条件は 1 行にまとめたまま、その行を「絞り込み」ボタンで開け閉めする（2026-11-14、下の「ツールバー」） |
| 場所を移ったときの条件 | **今のまま**。場所を移ると絞り込みは解除する（同じ場所を選び直したときは残す）。種類だけは残す（種類はサイドバーの範囲。[KINDS.md](KINDS.md)） |

## サイドバー（場所）

上から次の順。どれも押すとその一覧を開く。

| まとまり | 項目 |
|---|---|
| 見るもの | すべて、未分類、タグなし |
| 印 | お気に入り、ピン留め |
| 整理（枠で囲む） | 重複の候補（画像を使うライブラリだけ）、ゴミ箱 |
| 集めたもの | フォルダ、スマートフォルダ、タグ |

- 作業台はサイドバーから外し、「シェルフ」にする（今は詳細パネルのタブ）
- タグの行は、選ぶとその行が選択中になる（フォルダと同じ見た目）。タグの名前・色の変更と削除は、今どおり右クリックで行う
- タグの節の見出しにあった「いずれか／すべて」の切り替えは無くす（絞り込みの行の「タグ」へ移る）

## ツールバー

**ふだんは 1 行**。絞り込みの行は利用者が開いたときだけ 2 行目に出る（2026-11-14。Eagle と同じ考え方：絞り込み・並び順などは部品の中に隠し、サムネイルの大きさだけを常に出す）。

```text
1 行目  [サイドバー] タイトル 件数 [この表示の操作] ……… [−●＋] [絞り込み 2] [表示▾] [外観] [検索……] [詳細パネル]
2 行目  評価▾ タグ▾ 形式▾ サイズ（px）▾ 追加日▾ 容量▾ 紐づけ▾ ………………… すべて解除 条件を保存   ← 開いたときだけ
```

### なぜ変えたか（2026-11-14）

- 2 行がいつも出ていて、1 行目は真ん中が空いているのに、2 行目には絞り込み 7 つと表示の操作がぎっしり並んでいた
- 並び順・グループ・レイアウトは一度決めたらあまり変えない。絞り込みも毎回は使わない。いつも使うのはサムネイルの大きさくらい
- 一覧に使える高さを 1 行分増やす

### 1 行目

| 部品 | 決定 |
|---|---|
| この表示の操作 | タイトル・件数の右。フォルダの「サブフォルダの内容も表示」、重複の候補の「似ている度合い」と「まとめて整理…」、ゴミ箱の「ゴミ箱を空にする」（[UI.md](UI.md)） |
| サムネイルの大きさ | **常に出す**（−●＋）。リストのレイアウトでは無効表示。⌘+ / ⌘- も今どおり |
| 絞り込み | 押すと 2 行目（絞り込みの行）を開け閉めする。条件を付けているときは塗り（`tonal`）にし、条件の数を出す（「絞り込み 2」）。閉じていても条件は効いたまま |
| 表示 | 今の ⚙ を置き換えるポップオーバー。アイコンは今のレイアウトのもの。中身は下の「表示のポップオーバー」 |
| 外観・検索・詳細パネル | 今のまま |

### 絞り込みの行（2 行目）

並ぶ条件（左から）：評価、タグ、形式、サイズ（px）、追加日、容量、紐づけ（親子の紐づけを使うライブラリだけ。末尾に置くので、ほかの条件の位置は変わらない。[LINKS.md](LINKS.md)）。種類はサイドバーの範囲（[KINDS.md](KINDS.md)）で、ここに出るのはスマートフォルダの条件を見せるときだけ（末尾）

- **開け閉めは利用者の操作のときだけ**（[UI.md](UI.md) の例外「利用者が自分で開け閉めするもの」）。「絞り込み」ボタン、⌘⇧F（開いて最初の条件へフォーカス）、メニューバーの「表示 › 絞り込みの行」。開いているかは `localStorage` に覚える
- スマートフォルダを開いている間は、その条件を見せるために開いて出す。ほかの場所へ移ったら、利用者が選んでいた開け閉めに戻す
- 閉じたときも条件は外さない。効いていることは、ボタンの塗りと数、タイトルの「5 / 306 件」で分かる
- 条件のボタン・メニュー・件数の数え方は今のまま（下の「実装で決めたこと」）
- 右端に「すべて解除」と「条件を保存」（スマートフォルダとして保存）。条件が無いときも消さずに無効表示にする
- 合うものが無いときは、一覧に「条件に合うものはありません」と「絞り込みをすべて解除」を出す
- 絞り込み中はタイトルの件数を「5 / 13 件」の形にする
- 狭いときは条件が横にスクロールし、「すべて解除」「条件を保存」は右端に残す

### 表示のポップオーバー

今の ⚙ の中身に、帯に並べていた表示の操作を入れる。上から：

```text
レイアウト        [標準][Pinterest風][グリッド][リスト]     ← セグメント（アイコン＋名前）
並び順            [追加日 ▾] [↑↓]
グループ          [なし][年月][評価][タグ][フォルダ]        ← 重複の候補では無効表示
紐づけ            [すべて閉じる][すべて開く]               ← 紐づけを使うライブラリだけ
──────────
サムネイルの下に表示   ☑ 名前 ☑ サイズ（px） ☑ 評価 ☑ 形式・容量
```

- 選んでもポップオーバーは閉じない（続けていくつか変えられる。Eagle と同じ）。外をクリックするか Esc で閉じる
- サムネイルの大きさは 1 行目にあるので、ここには置かない（同じ操作を 2 か所に置かない）
- 同じものはメニューバーの「表示」にもある（レイアウト・グループ・並び順）。グループの切り替えは 2 クリックになるが、メニューバーとキーで補う

### 条件のボタン

- 条件は丸いボタン。押すとメニューが開き、選択肢と件数を出す。件数は **ほかの条件を付けたまま** 数える
- 使っている条件は塗り（アクセント色）にし、値を出す（例「タグ 本文・見出し」）。▾ の位置に × を出して、その条件だけ解除できる。
  値が長いときは省略し、隣の条件を押し出さない（[UI.md](UI.md)）
- 1 つの条件の中で複数選んだものは「いずれか」。条件どうしは「すべて」
  - 評価は「★n 以上」から 1 つ、追加日は期間から 1 つ選ぶ
  - タグは「いずれか／すべて」をメニューの中で切り替える
- スマートフォルダを開いているときは、その条件を絞り込みの行に読み込んで表示する（「条件を編集」で変えられる）

## 実装で決めたこと

| 論点 | 決定 |
|---|---|
| 件数の数え方 | `facet_counts`（`db.rs`）が今の問い合わせに合うものを条件ごとに数える。各メニューは開いたときに、その条件だけを外した問い合わせ（`listQuery(s, key)`、`store.ts`）で数え直す。開いたまま別の条件を変えたら数え直す |
| 「5 / 13 件」の分母 | その場所の件数（サイドバーと同じ数。サブフォルダ表示ならその合計、`placeTotal`）。分母が分からない場所（重複の候補）は今までどおり件数だけ |
| 狭いとき | 行は 1 行のまま。条件は横にスクロールし、「すべて解除」「条件を保存」は右端に残す。メニューはウィンドウに対して出す（行で切れない） |
| 表示の行が狭いとき | ~~並び順・グループ・レイアウト・表示の設定は右端のまま。…~~ → 表示の操作はポップオーバーへ入れた（2026-11-14）。1 行目の畳み方は [UI.md](UI.md)「畳む順番」 |
| 「種類」 | いま 2 種類以上が使われているときだけ出す（1 種類しか無いライブラリでは選ぶものが無い）。重複の候補では無効表示（画像だけが対象）。→ サイドバー上部の範囲のメニューへ移した（[KINDS.md](KINDS.md)） |
| 「サイズ（px）」（旧「画像サイズ」） | 縦長／横長／正方形と幅・高さ（px）。縦横を持つ画像と動画に効く。一覧が画像・動画だけのとき（サイドバーの「種類で絞る」で画像・動画を選ぶ、または形式で画像・動画の形式だけを選ぶ）に使え、ほかの種類が混ざると無効表示（[KINDS.md](KINDS.md)） |
| 「タグ」のメニュー | タグが 9 個以上あれば上に検索欄を出す。「いずれか／すべて」はメニューの上端 |
| 「すべて解除」 | 検索欄の文字と種類も含め、絞り込みの行の条件をすべて外す（場所を移るときと違い、種類も外す）。→ 種類を範囲にしたので、範囲は外さない（[KINDS.md](KINDS.md)） |
| タグの場所で「条件を保存」 | 開いているタグも条件に入れて保存する（保存したスマートフォルダが同じものを集めるように） |
| スマートフォルダを開いているとき | 条件は塗りのボタンで出すが、押しても変わらない（押すと「条件を編集」と同じく編集に入る）。検索の文字は「検索」のボタンで出す。右端は「条件を編集」。編集中は「「名前」の条件を編集中」と「キャンセル」「保存」 |
| ⌘⇧F | 絞り込みの行の、使える最初の条件へフォーカスを移す（メニューバー「編集」→「絞り込みへ」）。閉じていれば開いてから（2026-11-14） |
