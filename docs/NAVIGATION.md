# サイドバーとツールバーの役割：場所・絞り込み・表示

**実装済み**（下の「実装で決めたこと」）。

使っていて困っていること：

- 絞り込みが 4 か所に散っている。サイドバーのタグとフォントの言語・書体・太さ・特徴、ツールバー 2 段目の種類と評価、
  1 段目のボタンで開く絞り込みバー（形式・画像サイズ・追加日・容量）
- サイドバーのフォルダとタグは同じ見た目の行なのに、フォルダは「そこへ移る」、タグは「今の一覧に条件を重ねる」と働きが違う
- 条件を付けると「絞り込み中」の行が増え、一覧が下にずれる（[UI.md](UI.md) の原則に反する）

## 決定

役割を 3 つに分け、置き場所を 1 つずつにする。

| 役割 | 問い | 置き場所 | 選び方 |
|---|---|---|---|
| **場所** | どこを見るか | サイドバー | 1 つだけ選ぶ |
| **絞り込み** | その中をどう絞るか | ツールバーの絞り込みの行（常に出す） | 重ねて使える |
| **表示** | どう見せるか | ツールバーの表示の行 | 並び順・グループ・レイアウト・大きさ |

| 論点 | 決定 |
|---|---|
| サイドバーのタグ | **場所にする**。フォルダと同じく、押すとそのタグの一覧を開く（1 つだけ）。「フォルダの中をタグで絞る」「複数タグのいずれか／すべて」は絞り込みの行の「タグ」で行う |
| フォントの言語・書体・太さ・特徴 | サイドバーから外し、**絞り込みの行へ移す**。件数は各条件のメニューの中に出す |
| 絞り込みの置き場所 | **常に出ている 1 行にまとめる**。絞り込みボタン（⌘⇧F で開くバー）と「絞り込み中」の行は無くす |
| 場所を移ったときの条件 | **今のまま**。場所を移ると絞り込みは解除する（同じ場所を選び直したときは残す）。ストックモードの種類だけは残す |

## サイドバー（場所）

上から次の順。どれも押すとその一覧を開く。

| まとまり | 項目 |
|---|---|
| 見るもの | すべて（フォントモードは「すべてのフォント」）、未分類、タグなし。フォントモードでは「この端末のフォント」（読み取り専用。[SYSTEM_FONTS.md](SYSTEM_FONTS.md)） |
| 印 | お気に入り、ピン留め |
| 整理（枠で囲む） | 重複の候補（ストックモードだけ）、ゴミ箱 |
| 集めたもの | フォルダ、スマートフォルダ、タグ |

- 作業台はサイドバーから外し、「シェルフ」にする（今は詳細パネルのタブ。[FONT_UI.md](FONT_UI.md)）
- タグの行は、選ぶとその行が選択中になる（フォルダと同じ見た目）。タグの名前・色の変更と削除は、今どおり右クリックで行う
- タグの節の見出しにあった「いずれか／すべて」の切り替えは無くす（絞り込みの行の「タグ」へ移る）

## ツールバー

```text
1 段目  [サイドバー]  タイトル  件数            [検索……………]  [追加]  [詳細パネル]
2 段目  見本の文字の行（フォントモードだけ。どのレイアウトでも出す）
3 段目  絞り込み：評価▾ タグ▾ …                          すべて解除  条件を保存
4 段目                      並び順▾ ↕ │ グループ[…] │ レイアウト[…] ⚙
```

### 絞り込みの行

| モード | 並ぶ条件（左から） |
|---|---|
| ストック | 評価、タグ、種類、形式、画像サイズ、追加日、容量、紐づけ（親子の紐づけを使うライブラリだけ。末尾に置くので、ほかの条件の位置は変わらない。[LINKS.md](LINKS.md)） |
| フォント | 評価、タグ、言語、書体、太さ、特徴、形式、追加日 |

- 条件は丸いボタン。押すとメニューが開き、選択肢と件数を出す。件数は **ほかの条件を付けたまま** 数える
- 使っている条件は塗り（アクセント色）にし、値を出す（例「タグ 本文・見出し」）。▾ の位置に × を出して、その条件だけ解除できる。
  値が長いときは省略し、隣の条件を押し出さない（[UI.md](UI.md)）
- 1 つの条件の中で複数選んだものは「いずれか」。条件どうしは「すべて」
  - 評価は「★n 以上」から 1 つ、追加日は期間から 1 つ選ぶ
  - タグは「いずれか／すべて」をメニューの中で切り替える
- 右端に「すべて解除」と「条件を保存」（スマートフォルダとして保存）。条件が無いときも消さずに無効表示にする
- 合うものが無いときは、一覧に「条件に合うものはありません」と「絞り込みをすべて解除」を出す
- 絞り込み中はタイトルの件数を「5 / 13 件」の形にする
- スマートフォルダを開いているときは、その条件を絞り込みの行に読み込んで表示する（「条件を編集」で変えられる）。今の 2 段目の「条件: …」の表示は無くす

### 表示の行

並び順、昇順／降順、グループ、レイアウト、表示の設定。右に寄せ、表示を切り替えても位置を変えない。

## 今の実装から変わるところ

| 今 | これから |
|---|---|
| `Sidebar.tsx` の `TagList`：`tagFilter` を切り替える（条件） | タグを `View`（`{ kind: "tag", id }`）として開く |
| `features/fonts/FontFilters.tsx`：サイドバーの節 | 絞り込みの行の条件（言語・書体・太さ・特徴）。件数はほかの条件と同じく `facet_counts` で数える |
| `Toolbar.tsx`：2 段目の `KindFilter` と評価の星 | 絞り込みの行の「種類」「評価」 |
| `FilterBar.tsx`：⌘⇧F で開くバー（形式・画像サイズ・追加日・容量） | 絞り込みの行の条件。⌘⇧F は絞り込みの行の先頭へフォーカスを移すキーにする |
| `Toolbar.tsx` の `ActiveFilters`（絞り込み中の行） | 無くす（条件ボタンが値を出す） |
| タグの「いずれか／すべて」（`tagMatchAll`）：サイドバーの見出し | 絞り込みの「タグ」のメニューの中 |

ショートカット一覧・メニューバー・`docs/FEATURES.md` の「絞り込み」の説明も合わせて直す。

## 実装で決めたこと

| 論点 | 決定 |
|---|---|
| 件数の数え方 | `facet_counts`（`db.rs`）が今の問い合わせに合うものを条件ごとに数える。各メニューは開いたときに、その条件だけを外した問い合わせ（`listQuery(s, key)`、`store.ts`）で数え直す。開いたまま別の条件を変えたら数え直す |
| 「5 / 13 件」の分母 | その場所の件数（サイドバーと同じ数。サブフォルダ表示ならその合計、`placeTotal`）。分母が分からない場所（重複の候補）は今までどおり件数だけ |
| 狭いとき | 行は 1 行のまま。条件は横にスクロールし、「すべて解除」「条件を保存」は右端に残す。メニューはウィンドウに対して出す（行で切れない） |
| 表示の行が狭いとき | 並び順・グループ・レイアウト・表示の設定は右端のまま。ツールバーの幅が 768px を切るとグループのセグメントを同じ場所のメニュー（「グループ なし ▾」）に畳み、さらに狭いと「グループ」の語をアイコンにする。それでも入らないときは折り返す（切れて押せなくはしない） |
| 「種類」 | ストックでいま 2 種類以上が使われているときだけ出す（1 種類しか無いライブラリでは選ぶものが無い）。重複の候補では無効表示（画像だけが対象） |
| 「画像サイズ」 | 縦長／横長／正方形と幅・高さ（px）。一覧が画像だけのときに使え、ほかの種類が混ざると無効表示 |
| 「タグ」のメニュー | タグが 9 個以上あれば上に検索欄を出す。「いずれか／すべて」はメニューの上端 |
| 「すべて解除」 | 検索欄の文字と種類も含め、絞り込みの行の条件をすべて外す（場所を移るときと違い、種類も外す） |
| タグの場所で「条件を保存」 | 開いているタグも条件に入れて保存する（保存したスマートフォルダが同じものを集めるように） |
| スマートフォルダを開いているとき | 条件は塗りのボタンで出すが、押しても変わらない（押すと「条件を編集」と同じく編集に入る）。検索の文字は「検索」のボタンで出す。右端は「条件を編集」。編集中は「「名前」の条件を編集中」と「キャンセル」「保存」 |
| ⌘⇧F | 絞り込みの行の、使える最初の条件へフォーカスを移す（メニューバー「編集」→「絞り込みへ」） |
