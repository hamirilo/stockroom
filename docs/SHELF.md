# シェルフ：集めたものを順番どおりに使う

> 状態：決定・実装済み（2026-11-14）。

機能を足していくと、複数選択したときの選択バーとシェルフの違いがあいまいになる。どちらに何を置くかを決める基準として、シェルフを定義する。

## 定義

**シェルフは、一覧や場所をまたいで「あとで一緒に使うもの」を一時的に集めておく、順番のある作業台。集めたものを見比べ、並べ、まとめて外へ出すためにある。ライブラリの中身は変えない。**

- **場所をまたぐ**：選択は、ほかのフォルダや検索へ移ると消える。シェルフは空にするまで消えない（アプリを閉じても残る）
- **順番がある**：入れた順に並び、並べ替えられる。比較・まとめて出力・書き出しの連番は、この順番で行う
- **一時的**：作業が終わったら空にする（中身はライブラリに残る）。ずっと取っておく分類は、フォルダやタグで行う
- **ライブラリに 1 つ**：名前を付けた複数のシェルフは作らない（それはフォルダの役目）

## 選択バーとの分け方

| | 選択と選択バー | シェルフ |
|---|---|---|
| ひとことで | いま選んでいるものを、**変える** | 集めたものを、**順番どおりに使う** |
| 効く範囲 | いまの一覧の中だけ。ほかへ移ると消える | 場所をまたいで残る |
| 置く操作 | ライブラリの中身を変えるもの：お気に入り・ピン留め・回転・フォルダへ移動・タグ・評価・ゴミ箱（[MENUS.md](MENUS.md) §7） | 順番どおりに使う：比較・まとめて出力・書き出し（シェルフの順に連番）・別のライブラリへ。シェルフを整える：並べ替え・外す・空にする・中を見る |
| 置かない操作 | 比較、シェルフの順番を使う操作 | タグ・フォルダ・評価・名前の変更・ゴミ箱 |

**つなぐもの**：シェルフを「一覧に広げる」だけ。広げると、シェルフの中身が一覧の場所に出る（ほかのフォルダにあるものも全部）。そこで選べば、選択バーでタグ付けや移動ができる。「選択は一覧の中だけ」の約束はそのまま。

### 新しい機能をどちらに置くか

1. ライブラリの中身を変える → **選択バー**（シェルフには置かない）
2. 順番や、場所をまたいで集めたものが前提 → **シェルフ**
3. どちらでもない出力（書き出しなど）→ 両方に置いてよい。順番を使う部分（連番など）はシェルフだけ

## 決めたこと

| 論点 | 決定 |
|---|---|
| 見せ方 | 見出しの［タイル｜リスト］で切り替える。タイルは画像だけを正方形で並べ、左上に順番の番号。名前はツールチップ、ホバーで ×。どちらで見ていたかは覚えておく（`localStorage`） |
| 置き方 | 詳細パネルの［情報｜シェルフ］のタブ（今と同じ）と、情報の下にシェルフを並べる上下の分け方を、利用者が切り替えられる（シェルフの「…」のメニュー、`shelfLayout`）。上下のときは境目の帯をドラッグで高さを変え（`shelfHeight`、パネルの 70% まで）、帯を押すとシェルフを見出しだけに畳む（`shelfFolded`）。⌘⌥3 も畳む・開く。一覧からのドラッグ中は畳んでいても開いて見せる |
| 広げる | **同じシェルフを一覧の場所に広げる**（別の一覧を開くのではない）。広げたシェルフには［一覧｜比較］の 2 つの見せ方があり、ツールバーで切り替える。一覧＝ふだんのサムネイルで並べ、選んで選択バーで手を入れる。比較＝画像だけを大きく並べ、拡大・移動を一緒に動かす（[COMPARE.md](COMPARE.md)。今の「比較する」はこの見せ方になる）。右のタブの「比較する」は比較で、「一覧に広げる」は一覧で開く |
| 広げているあいだ | 右のタブには「シェルフを広げています（一覧）［戻す］」だけを出し、同じ中身を 2 か所に並べない。ツールバーのタイトルは「シェルフ N 件」、「この表示の操作」は［一覧｜比較］・「…」（まとめて出力・書き出し・別のライブラリへ・すべて選択・空にする）・戻す の 3 つだけ（ツールバーが狭くても収まるように。全部を並べると右側の部品の下にもぐった）。グループ分けはせず、並び順はシェルフの順。広げているあいだは、ほかのフォルダを見ながら足すことはできない（戻してから足す） |
| 入口 | シェルフのボタンだけ。サイドバーに「シェルフ」の場所は増やさない（[NAVIGATION.md](NAVIGATION.md) で作業台をサイドバーから外した決定のまま） |
| 空にする | 見出しの行に名前付きで出す（「…」の中に隠さない）。中身はライブラリに残り、元に戻せる |
| 書き出しの連番 | シェルフから書き出すとき、「シェルフの順に番号を付ける」を選べる（`001_元の名前`）。ライブラリの中の名前は変えない |
| 中を見る | シェルフの項目で Space（またはダブルクリック、右クリックの「大きく見る」）を押すと、シェルフを一覧に広げてから、一覧と同じビューアで大きく見る。シェルフの中を前後に送れる |
| タグ・フォルダ | シェルフには置かない。広げて選び、選択バーで行う。そのため選択バーに「タグ…」を足す（今のタグ付けは詳細パネルと ⌘⇧C / ⌘⇧V だけ） |
| シェルフの中で複数選んで外す | 置かない。シェルフの中にもう 1 つの「選択」ができて紛らわしい。広げて選び、B（シェルフから外す）を押す |
| ライブラリの名前を連番に変える | シェルフの機能ではない。作るなら選択バー側の別の機能として考える |

## 実装

| 部分 | 場所 |
|---|---|
| 広げる・戻す | `store.ts` の `openShelf` / `closeShelf`（`view` を `tray` にし、戻り先を `shelfReturn` に覚える）。`comparing` は広げたシェルフの比較の見せ方のときだけ true（`setComparing(true)` は広げていなければ広げてから）。`listQuery` は `tray` のとき並び順を手動（シェルフの順）にし、`arrange` はグループ分けしない |
| 広げたシェルフのツールバー | `Toolbar.tsx` の `ShelfViewControls` |
| シェルフ本体 | `Shelf.tsx`（タイル `Tile`・リスト `Chip`、広げているあいだの表示、`viewOnShelf`） |
| 上下の置き方 | `DetailsPanel.tsx` の `SplitPanel` |
| 選択バーの「タグ…」 | `SelectionBar.tsx` の `TagButton`（入力欄は `Inspector.tsx` の `TagInput`） |
| 書き出しの連番 | `ExportDialog.tsx`（`numberPrefixes`、「シェルフの順に番号を付ける」は前回の選択を覚える。初めては オン）、`export.rs` の `export_items(…, prefixes)` |

## 検討の記録

- 見本：シェルフ 定義と整理案、シェルフと選択バー 定義の見本、シェルフ 広げる・分ける（2026-11-14、Artifact）
- 「シェルフのものを選ぶ」（いまの一覧で選ぶ）は、ほかのフォルダにあるものを選べないのでやめ、「一覧に広げる」にした
- 「集める場所（右のタブ）と使う場所（広げた一覧）に分ける」案は、比較までの手順が 1 つ増え、開いているあいだ同じ中身が 2 か所に出るので採らなかった
